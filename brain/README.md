# Excavatortron Brain (Obsidian vault)

This folder is an **Obsidian vault** — the project's knowledge base as a set of
linked Markdown notes. Open this `brain/` folder as a vault in Obsidian and start
at **[[Excavatortron Brain]]** (the home note / map of content).

- New to the project? Read [[Excavatortron Brain]] → [[Architecture]] → [[Skills vs Tools]].
- Operating it? See [[Operations and Setup]].
- Want Claude to read/write these notes? See [[Obsidian Access (MCP)]].

Everything here is plain Markdown with `[[wikilinks]]`, so it also renders fine on
GitHub — but the graph view, backlinks, and search only light up inside Obsidian.
