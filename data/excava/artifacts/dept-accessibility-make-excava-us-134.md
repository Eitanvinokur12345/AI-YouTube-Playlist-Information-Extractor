# accessibility: Make EXCAVA usable by EVERYONE — contrast, mobile/touch, reduced-motion, keyboard nav, scr

> Decision artifact · room `dept-accessibility-make-excava-us-134` (dept) · 2026-07-18T02:28:54.727200+00:00
> Participants: Ramp, Reader, Access · synthesized by mistral/mistral-small-latest

**Decision:** Implement a persistent, compact, high-contrast skip link at the top of every page.

**Plan:**
1. Design a small, high-contrast skip link (e.g., arrow/icon) that remains visible at all times.
2. Ensure the skip link is keyboard-navigable and programmatically associated with the main content.
3. Test with first-time keyboard users to confirm discoverability and usability.
4. Add the skip link to the top of every page in the EXCAVA template.
5. Document the skip link’s purpose and behavior in the accessibility guidelines.
6. Monitor feedback and iterate if issues arise.

**What changed:** Added a persistent, compact skip link for immediate keyboard navigation.
