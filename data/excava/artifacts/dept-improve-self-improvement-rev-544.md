**Decision:** Run a 2-week pilot on one team already using PR-Agent’s light-risk flagging to measure review-time impact and signal-to-noise ratio.

**Plan:**
1. Select a pilot team already using PR-Agent’s light-risk flagging (no setup cost).
2. Enable PR-Agent in shadow mode *only* for this team’s PRs for 2 weeks.
3. Measure review time and signal-to-noise ratio (false positives vs. useful feedback).
4. Collect feedback from reviewers on perceived noise vs. value.
5. If signal-to-noise improves, expand to other teams; if not, drop the pilot.
6. Deliver metrics and decision to stakeholders by pilot end.

**What changed:** Pilot scope narrowed to one team for cost efficiency.
