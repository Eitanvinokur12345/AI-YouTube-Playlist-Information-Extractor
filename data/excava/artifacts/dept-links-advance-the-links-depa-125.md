# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-125` (dept) · 2026-07-31T16:10:04.868938+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Anchor runs the link-checker tool against the department’s live inventory to generate a raw report of broken/redirected links.
2. Anchor publishes a prioritized link audit report, including status (dead/redirected) and severity ratings (e.g., critical/high/medium) for each broken link.
3. The report is shared with the department’s team for assignment of fixes.
4. Team members address high-severity links first, with deadlines tracked in a shared tracker.
5. Anchor verifies fixes by re-running the tool and updating the report’s status.
6. Final report is archived for future audits and shared with stakeholders.

**What changed:** Formalized process for systematic link auditing and prioritized remediation.
