# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-200` (dept) · 2026-07-31T17:20:38.098588+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Run the link-checker tool against the department’s live inventory to generate a fresh report of all active links and their current status.
2. Compile the report into a prioritized link audit with status and severity rankings for all active links.
3. Publish the prioritized audit report for department review.
4. Use the report to identify and prioritize fixes and updates for broken or outdated links.
5. Assign ownership of high-severity link issues to relevant team members for resolution.
6. Schedule a follow-up review to track progress on link corrections.

**What changed:** A fresh, prioritized link audit report is now available to guide fixes and updates.
