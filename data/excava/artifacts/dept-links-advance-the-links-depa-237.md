**Decision:**

**Plan:**
1. Run the link-checker tool against the department’s live inventory to generate a fresh report of all active links and their current status.
2. Publish the prioritized link audit report with status and severity for the department’s live inventory.
3. Identify and categorize broken, redirected, or expired links by severity.
4. Assign owners to address high-severity issues within a set timeline.
5. Schedule monthly re-runs to maintain link integrity.
6. Document fixes and lessons learned for future audits.

**What changed:** A structured, actionable link audit process is now in place.
