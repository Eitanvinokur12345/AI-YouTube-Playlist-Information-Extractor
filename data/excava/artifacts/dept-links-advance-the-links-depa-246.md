# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-246` (dept) · 2026-07-31T22:51:09.638771+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Anchor runs the link-checker tool on the department’s current link inventory.
2. Anchor compiles a verified list of active links and a broken link audit report.
3. Anchor shares both the verified list and audit report with the links team.
4. The links team reviews the audit report to prioritize updates/removals.
5. The team schedules and executes corrections for broken/outdated links.
6. Anchor documents the changes in the department’s link inventory log.

**What changed:** Broken/outdated links will be systematically identified and addressed to improve link quality.
