# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-294` (dept) · 2026-07-31T18:02:29.666244+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Anchor runs the link-checker tool against the live inventory to generate a fresh report of all active links and their statuses.
2. Anchor publishes the prioritized link audit report with severity levels on the Mission Control Dashboard.
3. The links department reviews the report to identify critical broken, redirected, or outdated links.
4. Assign owners to address high-severity issues within a set timeline (e.g., 48 hours).
5. Schedule a follow-up review to verify fixes and update the report.
6. Document lessons learned to improve future link maintenance processes.

**What changed:** A real-time, prioritized link audit report is now published on the Mission Control Dashboard for immediate action.
