# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-301` (dept) · 2026-07-30T19:17:42.605949+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Anchor runs the link-checker tool against the live inventory of Mission Control Dashboard links.
2. Anchor generates a prioritized report of broken or outdated external links.
3. Anchor shares the report with the team for immediate review.
4. Team reviews the report and identifies links requiring updates or removals.
5. Team assigns owners to address flagged links within a set timeline.
6. Anchor verifies fixes and updates the Mission Control Dashboard accordingly.

**What changed:** External links in the Mission Control Dashboard will now be systematically audited and corrected.
