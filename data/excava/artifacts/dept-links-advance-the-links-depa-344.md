**Decision:**

**Plan:**
1. Anchor runs the link-checker tool against the department's live inventory to generate a full report.
2. Anchor categorizes broken, redirected, and outdated links with severity levels (e.g., critical, high, medium).
3. Anchor compiles a prioritized list of actionable fixes for the team.
4. Anchor publishes the prioritized link audit report in GitHub markdown format.
5. The team reviews and assigns fixes based on the report.
6. Anchor schedules follow-up checks to validate resolved links.

**What changed:** A structured, prioritized link audit report is now available for the team to address broken/outdated links.
