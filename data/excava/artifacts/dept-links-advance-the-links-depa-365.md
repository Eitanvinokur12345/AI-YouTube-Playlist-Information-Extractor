# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-365` (dept) · 2026-07-31T16:23:51.157566+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Run the link-checker tool against the department’s live inventory to identify broken links.
2. Generate a clean report showing broken links with direct links to affected pages.
3. Publish the prioritized link audit report with status and severity for each broken link.
4. Flag broken links for review and assign owners for remediation.
5. Track progress in a shared dashboard for transparency.
6. Schedule a follow-up audit after fixes are implemented.

**What changed:** A structured link audit process is now in place to systematically identify and address broken links.
