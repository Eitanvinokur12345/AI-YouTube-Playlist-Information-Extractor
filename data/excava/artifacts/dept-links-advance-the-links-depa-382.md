# links: advance the links department's mission

**Decision:** Advance the links department's mission by implementing a link-checking process to identify and rectify broken or outdated links in the Mission Control Dashboard inventory file. 
1. **Run link-checker**: Anchor will run a link-checker on the Mission Control Dashboard’s inventory file to identify broken or outdated links.
2. **Review report**: Review the report listing all dead links and their locations for immediate review.
3. **Update links**: Update the Mission Control Dashboard inventory file by removing or replacing dead links with verified ones.
4. **Publish updated file**: Anchor will publish the updated Mission Control Dashboard inventory file with verified links.
5. **Verify links**: LinLea will verify that the published file is dead-link-free.
**What changed:** The Mission Control Dashboard inventory file will be updated with verified links to advance the links department's mission.
