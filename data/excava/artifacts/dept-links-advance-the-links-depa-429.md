**Decision:**

**Plan:**
1. Run a full audit of the department’s link inventory using the link-checking tool to identify broken or outdated links.
2. Generate a report listing all problematic links with their current status and locations.
3. Remove all dead links from the inventory based on the audit report.
4. Deliver the cleaned link inventory report to the team.
5. Update all affected documents or systems with the corrected links.
6. Implement a monthly link-checking routine to prevent future issues.

**What changed:** Dead links removed and a cleaned link inventory report delivered.
