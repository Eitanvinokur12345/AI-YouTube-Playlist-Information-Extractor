# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-489` (dept) · 2026-07-30T17:59:52.694300+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Run the link-checker tool against the department’s live inventory to generate a report of broken/outdated links and redirects.
2. Prioritize the report by severity levels (e.g., critical dead links, outdated redirects).
3. Deliver the prioritized report to the team for cleanup.
4. Assign cleanup tasks based on severity and track progress.
5. Verify fixes by re-running the link-checker on updated links.
6. Document lessons learned for future link maintenance.

**What changed:** Live inventory now has a prioritized, actionable report of broken/outdated links.
