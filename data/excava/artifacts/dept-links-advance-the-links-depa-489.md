# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-489` (dept) · 2026-07-31T21:00:14.215674+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Run the link-checker tool against the department’s live inventory to generate a prioritized report of broken links, redirects, and outdated URLs.
2. Rank the report by severity (e.g., broken links > redirects > outdated URLs).
3. Publish the report to the team with clear prioritization and severity levels.
4. Assign cleanup tasks based on severity and urgency.
5. Track progress and follow up on unresolved items weekly.
6. Update the department’s link inventory post-cleanup.

**What changed:** The team now has a prioritized, severity-ranked link audit report for immediate cleanup.
