**Decision:**

**Plan:**
1. Run the link-checker tool against the department’s live inventory to generate a raw report of all broken links.
2. Filter and prioritize the report to include only dead links, assigning severity levels (e.g., high/medium/low) based on impact.
3. Deliver the prioritized report to the department for immediate review and action.
4. Assign owners to address each broken link based on severity and resource availability.
5. Schedule a follow-up review within 1 week to confirm resolution progress.
6. Document recurring link issues to inform future inventory maintenance policies.

**What changed:** Prioritized, severity-ranked broken link report now delivered for targeted remediation.
