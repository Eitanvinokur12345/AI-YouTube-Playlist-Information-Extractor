# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-570` (dept) · 2026-07-31T11:21:48.399333+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Anchor runs a live audit of the department’s link inventory using the link-checker tool to generate a real-time report of broken and outdated links.
2. Anchor compiles the prioritized list of dead links and expired redirects from the audit report.
3. Anchor publishes the prioritized link audit report on GitHub by EOD today.
4. Team reviews the report and assigns cleanup tasks for high-priority dead links.
5. Team schedules a follow-up review within 48 hours to track progress on link fixes.
6. Anchor documents the audit process and findings in the department’s internal wiki for future reference.

**What changed:** A structured, time-bound plan for auditing and cleaning up broken links was formalized.
