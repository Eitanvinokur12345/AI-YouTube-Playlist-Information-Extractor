# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-633` (dept) · 2026-07-31T15:47:43.464689+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Anchor runs the link-checker tool against the department’s live inventory to generate a raw report of broken/outdated links.
2. Anchor refines the report into a prioritized audit with status (broken/outdated) and severity (high/medium/low) for each link.
3. Anchor publishes the prioritized link audit report to the department’s shared repository or communication channel.
4. LinLea reviews the report for completeness and assigns ownership of fixes to relevant team members.
5. Team members address high-severity links first, followed by medium/low-severity links in subsequent sprints.
6. Anchor re-runs the link-checker tool weekly to validate fixes and update the report.

**What changed:** A structured, prioritized link audit process is now formalized for the department.
