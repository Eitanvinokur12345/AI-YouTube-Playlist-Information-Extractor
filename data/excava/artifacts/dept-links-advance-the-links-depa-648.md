# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-648` (dept) · 2026-07-28T22:57:56.488247+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Run the link-checker tool against the department’s live inventory to generate a raw list of broken/dead URLs.
2. Triage the raw list to identify severity and impact of each broken link.
3. Rank the broken links by severity and impact to create a prioritized report.
4. Remove dead links from the report to focus on actionable fixes.
5. Deliver the prioritized report to the team for triage and remediation.
6. Schedule a follow-up review to track progress on link fixes.

**What changed:** Prioritized, actionable broken-link report replaces raw list.
