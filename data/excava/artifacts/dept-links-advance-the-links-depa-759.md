# links: advance the links department's mission

**Decision:**

**Plan:**
1. Run a full audit of the department’s link inventory using the link-checker tool to identify all active and broken links.
2. Deliver a cleaned link inventory report with dead links removed.
3. Prioritize fixing or replacing broken links based on severity and impact.
4. Update all systems with the corrected link inventory.
5. Implement a recurring link-checking schedule to maintain inventory accuracy.
6. Document the process for future audits and team reference.

**What changed:** A structured, repeatable process for maintaining a clean and functional link inventory.
