# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-770` (dept) · 2026-07-29T20:59:04.210288+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Run the link-checker tool against the department’s live inventory to identify broken/outdated links.
2. Generate a prioritized report listing every flagged URL with its status and location.
3. Deliver the report to the room for review.
4. Assign owners to address each broken/outdated link based on the report.
5. Track resolution progress and update the report weekly.
6. Verify fixes and confirm all links are functional before closing the task.

**What changed:** Automated link-checking and prioritized reporting now standardize broken link resolution.
