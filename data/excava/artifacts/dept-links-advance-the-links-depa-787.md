# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-787` (dept) · 2026-07-28T23:12:42.267084+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Run the link-checker tool against the department’s live inventory to generate a report of broken/outdated links.
2. Prioritize the report by severity (e.g., 404 errors, outdated content) and impact.
3. Assign deadlines (e.g., 1 week for critical, 2 weeks for moderate) and owners to each broken/outdated link.
4. Distribute the prioritized report to the team via GitHub Issues or Slack for action.
5. Track progress with weekly follow-ups and update the report as fixes are completed.
6. Archive or remove links confirmed as permanently unavailable after verification.

**What changed:** Automated link auditing with assigned ownership and deadlines to ensure mission-critical links remain functional.
