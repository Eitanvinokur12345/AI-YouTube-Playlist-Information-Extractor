# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-934` (dept) · 2026-07-27T05:34:23.788091+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Run a full audit of the department’s link inventory using the link-checker tool to identify broken, outdated, or low-quality links.
2. Generate a cleaned link inventory report with dead links removed, including each link’s destination, last check date, and any errors found.
3. Share the report with the team for review and validation of corrections.
4. Update all affected materials (documents, websites, etc.) with the corrected links.
5. Implement a monthly automated link-checking process to maintain link quality.
6. Document the process for future audits and onboarding.

**What changed:** Links are now validated, cleaned, and maintained with a repeatable process.
