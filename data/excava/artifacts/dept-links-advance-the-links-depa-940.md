# links: advance the links department's mission

> Decision artifact · room `dept-links-advance-the-links-depa-940` (dept) · 2026-07-28T17:47:33.312248+00:00
> Participants: Anchor, LinLea · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. Run the link-checker tool against the department’s live inventory to generate a fresh report of all active links and their current status.
2. Filter the report to identify broken, redirected, or outdated links.
3. Prioritize the list of problematic links based on impact (e.g., high-traffic pages, critical resources).
4. Deliver the prioritized report to the team with actionable recommendations for fixes (e.g., update URLs, remove dead links).
5. Assign owners to address each broken/outdated link within a defined timeline.
6. Schedule a follow-up review to verify fixes and update the inventory.

**What changed:** A systematic, data-driven approach to link maintenance replaces ad-hoc checks.
