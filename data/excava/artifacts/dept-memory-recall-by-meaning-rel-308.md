# memory: Recall by meaning, relate elements, build the brain graph, embed unembedded elements.

> Decision artifact · room `dept-memory-recall-by-meaning-rel-308` (dept) · 2026-07-12T11:39:27.890427+00:00
> Participants: Graft, Prune, Root · synthesized by mistral/mistral-small-latest

**Decision:** Build one shared Memory Map in plain language, versioned and modular—each node (idea, connection, gap) lives as a separate, updatable entry with clear ownership.

**Plan:**
1. Create a GitHub repository with a single `memory-map.md` file as the root, structured as a graph of linked nodes.
2. Each node (idea, connection, gap) is a separate, numbered section with a clear owner (e.g., `## [Owner] Node Title`).
3. Enforce versioning by requiring pull requests for updates, with a designated team lead as final approver.
4. Use plain language summaries at the top of each node, with technical details linked as subsections or external references.
5. Schedule bi-weekly "prune sessions" to archive stale nodes and update connections.
6. Embed unembedded elements by mandating that new ideas are added as nodes before being referenced elsewhere.

**What changed:** Replaced the single artifact with a modular, versioned system to prevent stagnation while keeping the shared Memory Map as the core artifact.
