**Decision:**

**Plan:**
1. **Curate taste materials** by extracting high-quality screenshots from curated design websites (e.g., Beverage Cans, Awwwards, Dribbble) and label them in the hub with metadata (source, date, design pattern).
2. **Organize by pattern** into folders (e.g., `hero-sections`, `typography`, `color-palettes`) for quick team reference.
3. **Add context** to each screenshot: brief notes on why it’s valuable (e.g., "vibrant pink hero section," "bold typography hierarchy").
4. **Sync with team** via GitHub Issues or Slack to prioritize additions (e.g., "Add 10 more hero section examples by EOD").
5. **Automate where possible** (e.g., browser extensions to capture full-page screenshots or use tools like [Carbon](https://carbon.now.sh/) for code snippets).
6. **Review quarterly** to archive outdated trends and refresh with new inspirations.
