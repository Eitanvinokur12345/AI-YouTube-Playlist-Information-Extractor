**Decision:**

**Plan:**
1. Use Playwright MCP server to capture high-quality screenshots of target web interfaces (e.g., Cloudera).
2. Annotate screenshots with design patterns (e.g., layout, typography, color schemes).
3. Store annotated screenshots in the hub under `/design-patterns/` with clear filenames (e.g., `cloudera-dashboard-pattern.png`).
4. Extract reusable design elements (e.g., CSS snippets, component structures) from screenshots.
5. Organize patterns by category (e.g., dashboards, navigation, forms) in a structured folder hierarchy.
6. Document metadata (e.g., source URL, date captured) in a `README.md` for each pattern.
