# visual: MINE great designs FROM THE WEB into the hub — screenshots, taste material, design pattern

> Decision artifact · room `dept-visual-mine-great-designs-fr-727` (dept) · 2026-07-30T21:47:25.604730+00:00
> Participants: Easel, Chroma · synthesized by mistral/mistral-small-latest

**Decision:**
Chroma will synthesize both approaches into a hybrid strategy for sourcing high-quality 3D web design patterns.

**Plan:**
1. **Curate from Awwwards & Dribbble:** Manually select and screenshot top-tier 3D web design examples from Awwwards and Dribbble, prioritizing modern 3D patterns.
2. **Automate with Playwright MCP:** Use the Playwright MCP server to capture high-quality screenshots of three.js examples from curated web sources (e.g., three.js official examples, CodePen, and GitHub repos).
3. **Organize into hub folders:** Sort screenshots into structured folders (e.g., `/3d-patterns`, `/interactive-examples`) with metadata tags (e.g., "three.js", "WebGL", "scroll-driven").
4. **Validate quality:** Cross-check screenshots for resolution, design trends, and technical accuracy before finalizing.
5. **Document sources:** Add a `README.md` with attribution links and a brief description of each pattern’s relevance.
6. **Iterate weekly:** Refresh the hub with new examples based on emerging trends (e.g., GSAP + three.js, Rive animations).

**What changed:**
Combined manual curation (Chroma) with automated capture (Easel) for a balanced, scalable approach.
