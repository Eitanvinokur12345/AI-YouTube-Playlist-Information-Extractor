**Decision:**

**Plan:**
1. Use Playwright MCP to capture high-quality screenshots of target web pages (e.g., MCP servers, SaaS pricing pages).
2. Save each screenshot as "taste material" in the hub with descriptive filenames (e.g., `playwright-mcp-interface.png`, `saas-pricing-page.png`).
3. Organize screenshots into a `/taste-materials/` directory within the hub for easy retrieval.
4. Tag screenshots with metadata (e.g., `design-pattern`, `ui-component`, `pricing-layout`) for searchability.
5. Curate a "top picks" subset of screenshots for quick reference in `/taste-materials/featured/`.
6. Document the process in a `README.md` within the hub for team alignment.

**What changed:** Standardized screenshot capture and hub organization for design inspiration.
