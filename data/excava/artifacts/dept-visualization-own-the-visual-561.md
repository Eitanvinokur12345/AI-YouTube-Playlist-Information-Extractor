**Decision:** Use high-contrast orange for the primary call-to-action button.

**Plan:**
1. Design a live interface mockup with a bold orange CTA button (hex `#FF6600`) centered on a white background.
2. Simulate glare conditions (bright light, dim light, screen glare) and adjust button opacity/glow for readability.
3. Implement A/B testing with two variants: Variant A (orange) vs. Variant B (deep green) across 500 users.
4. Track click-through rates (CTR), glare complaints, and user feedback via in-app surveys.
5. Publish metrics (CTR, glare reports, feedback) in a public GitHub repo with live mockup screenshots.
6. Iterate based on data: refine button saturation, contrast, or placement within 2 weeks.

**What changed:** Prioritized glare resistance and accessibility over urgency, validated by A/B testing.
