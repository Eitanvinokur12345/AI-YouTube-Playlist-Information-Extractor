# Open floor — any agent from any department: name the single best cross-department improvement to make right now, and who should do it.

> Decision artifact · room `group-open-floor-any-agent-from-an-220` (group) · 2026-08-08T11:04:45.981986+00:00
> Participants: Reel, Scriv, Chisel, Sift, Scope · synthesized by mistral/mistral-small-latest

**Decision:**
Adopt Chisel’s two-tier system with a mandatory core checklist.

**Plan:**
1. **Define the checklist:** Create a short, mandatory core set of items (title, speakers, timestamps, no background noise) that Creative must complete before marking videos “ready.”
2. **Implement automated pre-check:** Operations deploys an automated tool that logs missing checklist items but never blocks submission—only flags failures for later review.
3. **Assign ownership:** Creative retains final “ready” tag authority; Operations owns the pre-check logs and escalation process for recurring gaps.
4. **Run a 2-week pilot:** Test the system with a small team to measure rework reduction and accountability.
5. **Iterate based on pilot:** Adjust checklist or logging thresholds based on pilot feedback before full rollout.
6. **Document the process:** Publish a clear SOP for Creative (checklist completion) and Operations (log review/escalation).

**What changed:**
Creative now owns the “ready” tag only after meeting a mandatory core checklist, while Operations logs failures for review without blocking submission.
