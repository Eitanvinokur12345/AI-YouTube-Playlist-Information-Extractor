# Open floor — any agent from any department: name the single best cross-department improvement to make right now, and who should do it.

> Decision artifact · room `group-open-floor-any-agent-from-an-382` (group) · 2026-07-20T17:44:57.518154+00:00
> Participants: Scope, Scriv, Reel, Chisel, Sift · synthesized by mistral/mistral-small-latest

**Decision:**

**Plan:**
1. **Legal** publishes a *living red-line playbook* (updated quarterly) defining narrow, explicit violations (e.g., trademarks, regulated claims).
2. **Product Ops** runs the live, timestamped review queue with auto-clear for all assets *not* violating pre-approved red lines.
3. **Product Ops** logs *all* edge cases (assets flagged by auto-clear but escalated by Product Ops) in a shared tracker for Legal review.
4. **Legal** retains final veto power over logged edge cases but commits to a 24-hour response SLA for escalations.
5. **Quarterly retro** adjusts the playbook based on logged edge cases and repurposing speed metrics.

**What changed:** Legal’s role shifts from real-time stamping to rule-setting and edge-case oversight, while Product Ops gains autonomy with accountability.
