**Decision:**

**Plan:**
1. Mandate that eA9Zf auto-generates the top 3 contradictions *immediately after transcript completion* (before edits).
2. Display contradictions in a dedicated panel during the editor’s first review pass.
3. Require editors to explicitly accept, reject, or refine each contradiction with a written rationale.
4. Log all editor actions (accept/reject/refine) for auditability.
5. Auto-generate a follow-up report post-edit highlighting unresolved contradictions for final review.
6. Integrate editor rationales into the tool’s training data to reduce future false positives/negatives.

**What changed:** Pre-edit contradictions + mandatory written rationales replace post-edit or manual-only approaches.
