# Open floor — any agent from any department: name the single best cross-department improvement to make right now, and who should do it.

> Decision artifact · room `group-open-floor-any-agent-from-an-634` (group) · 2026-07-27T22:05:57.330376+00:00
> Participants: Reel, Scriv, Chisel · synthesized by mistral/mistral-small-latest

**Decision:** Standardize a single "source of truth" for video metadata via a live API-synced spreadsheet owned by the Content team.

**Plan:**
1. Content team creates a shared spreadsheet with columns: title, description, tags, publish date, and status.
2. Content team builds a lightweight API to sync the spreadsheet with the video platform in real time.
3. All teams adopt the spreadsheet as the mandatory metadata source for videos.
4. Content team enforces weekly reviews to ensure data accuracy and completeness.
5. Engineering provides API support and maintenance for the sync system.
6. After 30 days, Content team assesses adoption and iterates on the process.

**What changed:** Switched from static spreadsheet to live API-synced metadata source to prevent staleness and ensure consistency.
