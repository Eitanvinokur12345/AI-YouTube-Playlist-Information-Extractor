IMPORTANT — ONCE A YEAR The cloud login token expires about once a year. When it does, the Analyze workflow fails with an authentication error and no new skills appear. This is the only recurring manual step in the whole system.
How to renew the token (takes ~2 minutes)
  1. On your PC, open a terminal and run: claude setup-token
  2. Log in and copy the token it prints.
  3. Open your repo on GitHub → Settings → Secrets and variables → Actions.
  4. Edit the secret CLAUDE_CODE_OAUTH_TOKEN_REAL, paste the new token, save.
  5. Done. The next scheduled run works again. (Optional: Actions → Analyze pending → Run workflow to verify now.)
