An honest census of every src/ module: what actually runs. Rebuilt every beat by src/inventory.py. Wired = CI or the beat runs it. Operator = a human/agent runs it from the shell (a documented CLI, e.g. git_safe). Orphaned = code imports it, but nothing runs that code. Dead = nothing imports it and nothing runs it — the only kind safe to retire.
