# Automated Code Migration

## Overview
Leveraging AI agents to automatically port code between different frameworks, update APIs, or refactor large codebases, ensuring tests pass and contracts remain consistent.

**Use case:** Migrating legacy code to new frameworks, updating dependencies across a large project, or applying consistent code style changes.

## Key steps
1. Provide clear definitions of the source and target frameworks.
2. Specify all required tests and API contract checks for successful migration.
3. Break down massive migrations into manageable, verifiable sub-goals if possible.
