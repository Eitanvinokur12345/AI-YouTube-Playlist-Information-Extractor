# planning-with-files

## Overview
A skill for AI agents to write plans, research, and progress into real files (e.g., task_plan.md, findings.md, progress.md) to maintain context across chats and keep the task alive.

**Use case:** When the job is too big for one chat, to prevent AI agents from losing context and forgetting previous steps.

## Key steps
1. Writes task_plan.md for planning.
2. Writes findings.md for research.
3. Writes progress.md to save current state and resume work.
