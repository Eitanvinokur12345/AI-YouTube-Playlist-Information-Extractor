# Disciplined AI Agent Workflow Design

## Overview
Designing AI agent workflows by assigning specific roles, skills, routing, project memory, and hands-offs to individual agents. This prevents a single AI agent from performing all development tasks (e.g., product manager, developer, tester, reviewer, release manager) and ensures proper scoping, testing, review, and documentation for improved code quality and reliability.

**Use case:** Improving the reliability and quality of AI-generated code by distributing responsibilities among specialized AI agents, especially for complex software development tasks.

## Key steps
1. Define clear, distinct roles for each AI agent (e.g., product manager, developer, tester, reviewer, release manager).
2. Implement routing mechanisms to direct tasks to the appropriate agent.
3. Utilize hands-off protocols to manage transitions between agents.
4. Maintain project memory to ensure agents have necessary context.
5. Distinguish between 'full lane' workflows for complex, sensitive tasks and 'fast lane' workflows for simple fixes.
