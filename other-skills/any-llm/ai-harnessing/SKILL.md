# AI Harnessing / AI System Design

## Overview
The ability to build scaffolding around an AI model to enable it to perform complex tasks by connecting it to apps, tools, actions, files, context, and skills. This includes structuring instructions and examples.

**Use case:** Creating advanced AI applications beyond simple chatbots.

## Key steps
1. Focus on connecting the model to external tools and data sources.
2. Provide clear context, examples, and instructions.
3. Design for modularity to easily switch between different AI models.
