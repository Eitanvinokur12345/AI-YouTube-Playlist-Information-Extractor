# Designing for AI Failure Modes

## Overview
Understanding and designing workflows or agent instructions to mitigate the specific failure modes of constrained (e.g., n8n) versus interpretive (e.g., Claude Code) AI systems.

**Use case:** Building robust and resilient AI-powered automations by accounting for their inherent limitations.

## Key steps
1. For constrained flows: rigorously test edge cases, monitor external API changes.
2. For interpretive agents: provide clear instructions, validate outputs for hallucinations, review changes.
