# AI-assisted tech stack planning

## Overview
Using an AI model to help plan an application's technical stack, including front-end, back-end, database, and deployment, by engaging in a continuous question-and-answer process.

**Use case:** Planning application architecture and selecting appropriate technologies.

## Key steps
1. Communicate with the AI model for at least 30-45 minutes.
2. Allow the AI to ask questions to refine your decisions.
3. Use the AI to think through different aspects of your application.
