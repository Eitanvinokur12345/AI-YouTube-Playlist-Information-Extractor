# ChatGPT Council Multi-Advisor Prompt

## Overview
Based on Stanford research showing ChatGPT's tendency to agree with the user, this technique prefixes prompts with a trigger phrase like "Ask the Council" to force the model to generate multiple opposing expert perspectives. It systematically counteracts sycophancy bias in LLM responses.

## Key Techniques
- Prefix with "Ask the Council:" to trigger multi-expert simulation
- Request explicit roles (optimist, skeptic, domain expert, devil's advocate)
- Ask for opposing views before asking for a synthesis

## How to Apply
1. Start your prompt with "Ask the Council:" or "Simulate a council of experts:"
2. State your question or decision clearly
3. Request 3-5 distinct expert personas with opposing viewpoints
4. Ask for each expert's specific concerns and recommendations
5. Request a final synthesis that acknowledges the tensions between views

## Examples
- "Ask the Council: Should I pivot my SaaS product to target enterprise customers?"
- "Ask the Council: What are the risks of using AI agents in production code deployment?"
