# ChatGPT Marketplace Selling & Negotiation Agent

## Overview
A 4-prompt ChatGPT workflow that turns photos of items into live Facebook Marketplace
listings, then keeps working after posting by negotiating with buyers on a recurring
schedule. It chains vision, copywriting, agentic browsing, and Scheduled Tasks together.

## Key Techniques
- Vision-based item identification and market-price estimation from photos
- High-converting marketplace listing copy generation
- Agentic browser posting (ChatGPT creates the listing directly, no copy-paste)
- Recurring Scheduled Tasks for ongoing buyer negotiation

## How to Apply
1. Upload photos of the items you want to sell.
2. Prompt 1: ask ChatGPT to identify each item, estimate current market value, and
   suggest a realistic selling price.
3. Prompt 2: ask ChatGPT to write a complete marketplace listing (title + description).
4. Prompt 3: tell ChatGPT to use its browser/agent mode to create the Facebook
   Marketplace listing directly, instead of copy-pasting the text yourself.
5. Prompt 4: schedule a recurring task (e.g. every 24 hours) for ChatGPT to check for
   new buyer messages and negotiate the best price on your behalf.

Demonstrated end-to-end in the source video: photos in → priced, listed, posted, and
followed up on automatically, with no manual relisting or back-and-forth typing.
