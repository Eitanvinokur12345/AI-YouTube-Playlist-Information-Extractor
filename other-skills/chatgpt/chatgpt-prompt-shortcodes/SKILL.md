# ChatGPT Prompt Shortcodes

## Overview
A set of ten named shorthand modifiers you append to a ChatGPT prompt to control response
style, depth and format on demand, instead of describing the desired style in full each time.

## Key Techniques
- Append a short, memorable code (ELI5, TLDR, truth mode, steel man, step-by-step, like a pro,
  table format, 80/20, Socratic questioning, audit-my-plan) to the end of a normal prompt.
- Combine codes with your actual question so the code only changes the *shape* of the answer.
- Reuse the same codes across many different questions/topics.

## How to Apply
1. Write your normal question or request.
2. Append the code that matches how you want the answer shaped, e.g. "...explain quantum
   computing. ELI5" or "...review this plan. Audit mode."
3. Swap codes to get different views of the same underlying question (e.g. TLDR then
   step-by-step for the same topic).

## Examples
- ELI5 → simplifies an explanation to a beginner level.
- TLDR → summarizes a lengthy text.
- Truth mode → gives a more honest, less hedged answer.
- Steel man → argues the strongest version of an opposing view.
- Step-by-step, like a pro, table format, 80/20, Socratic questioning, audit-my-plan — further
  named response-style codes from the same set.
