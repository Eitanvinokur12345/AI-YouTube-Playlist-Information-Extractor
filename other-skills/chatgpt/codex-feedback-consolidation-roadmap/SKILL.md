# Feedback Consolidation & Roadmap Prioritization via Codex

## Overview
A workflow that has Codex (in the ChatGPT desktop app) pull feedback from multiple sources at once (feedback board, app store reviews, customer emails), rank items by estimated ROI, then spin up a fresh thread to start building the top-ranked feature.

**Use case:** Turning scattered product feedback across several channels into a prioritized, ready-to-build roadmap in one prompt.

## Key steps
1. Point Codex at all your feedback sources at once (feedback board, app store, emails) in a single prompt instead of triaging each channel manually.
2. Ask it to rank consolidated feedback by ROI before deciding what to build next.
