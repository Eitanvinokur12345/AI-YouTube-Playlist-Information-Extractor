# Digital Identity Erasure Automation

## Overview
Utilizing AI to automate the process of identifying personal information on data broker sites and submitting removal requests.

**Use case:** Removing personal data from hundreds of websites to enhance privacy.

## Key steps
1. Ensure 'Agent mode' is enabled for automated web interaction.
2. Regularly recheck sites as data brokers can repopulate information.
