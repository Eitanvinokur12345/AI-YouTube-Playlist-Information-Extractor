# Generate a week’s worth of branded Instagram content using ChatGPT 5.5

## Overview
Use ChatGPT 5.5's thinking mode to generate seven unique Instagram post ideas, then use image mode with a website link to create branded images for each post automatically.

**Use case:** Rapidly produce a full week of Instagram content including captions and branded images in under a minute.

## Key steps
1. Enable thinking mode before generating content ideas for better quality.
2. Use image mode with your website URL to automatically extract branding assets.
3. Specify the number of posts (e.g., seven) in the prompt for precise output.
