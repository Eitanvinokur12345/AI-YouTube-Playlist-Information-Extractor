# Marketing Asset Creation

## Overview
Producing various marketing materials like banners, ads, and posters tailored for different platforms.

**Use case:** Streamlining the creation of a comprehensive set of marketing visuals for a product launch or campaign.

## Key steps
1. Clearly define the type of asset needed (e.g., website banner, Instagram post).
2. Specify design principles like 'cinematic', 'realistic', 'high-converting'.
3. Provide guidelines for text content or lack thereof for each asset type.
