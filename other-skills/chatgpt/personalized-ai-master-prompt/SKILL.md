# Personalized AI Master Prompt Framework

## Overview
Build a reusable master prompt that encodes your role, goals, business context, workflow preferences, and communication style so any AI acts as a trained personal assistant from the first message. Create one per key role in your life and reuse it across sessions and tools.

## Key Techniques
- Use pull prompting to have AI build your master prompt: "I want to create a master prompt for my role as [X]. Ask me all the questions you need."
- Save the resulting document as a PDF named after the role (e.g., "Master Prompt - CEO.pdf")
- Upload to any AI tool at the start of a session for instant personalization

## How to Apply
1. Say: "I want to create a master prompt for my role as [CEO / parent / VP Marketing]. Ask me all the questions you need to create it."
2. Answer each question conversationally (use voice-to-text)
3. Review the output and refine: "Update this, add X, you're missing Y"
4. Save as PDF: "Master Prompt - [Role Name].pdf"
5. Upload to any AI tool at session start, or paste into the system prompt field

## Examples
- A "Dan - CEO" master prompt that includes company context, team structure, product details, and communication style
- A "Dan - Father" master prompt for personal life planning with family context
- A marketer's master prompt with brand guidelines, target audience, and tone of voice
