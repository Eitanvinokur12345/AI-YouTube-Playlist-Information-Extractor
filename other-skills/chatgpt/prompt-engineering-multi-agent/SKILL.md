# Prompt Engineering for Multi-Agent Simulation

## Overview
Designing and implementing complex prompts that instruct a large language model to simulate multiple independent AI agents (advisors, peer reviewers, chairman) to analyze a question from different perspectives, identify flaws, find upsides, and synthesize a final, unbiased verdict. This technique aims to overcome inherent biases like 'yes-man' behavior in LLMs.

**Use case:** Decision making, critical analysis, problem-solving, generating diverse viewpoints, avoiding confirmation bias in AI responses.

## Key steps
1. Clearly define roles and thinking styles for each simulated agent.
2. Include mechanisms for peer review and synthesis.
3. Specify mandatory triggers for when the multi-agent system should activate.
4. Provide examples of questions that should and should not trigger the council.
