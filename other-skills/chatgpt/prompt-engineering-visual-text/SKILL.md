# Prompt Engineering for Visual and Textual Output

## Overview
Crafting effective prompts to elicit both visual redesigns and detailed textual information (like shopping lists and instructions) from an AI model.

**Use case:** Achieving specific, multi-modal outputs from AI for practical applications.

## Key steps
1. Break down complex requests into sequential prompts.
2. Be explicit about desired output formats (e.g., 'include exact Amazon links').
3. Iterate on prompts to refine results.
