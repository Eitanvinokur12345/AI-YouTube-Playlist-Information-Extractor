# Installing Claude Code

## Overview
Ability to install Claude Code using terminal commands on various operating systems.

**Use case:** Setting up the Claude Code development environment.

## Key steps
1. Use `curl -fsSL https://claude.ai/install.sh | bash` for macOS, Linux, or WSL.
2. Use `irm https://claude.ai/install.ps1 | iex` for Windows PowerShell.
3. Ensure to add Claude Code to your PATH environment variable for easy access.
