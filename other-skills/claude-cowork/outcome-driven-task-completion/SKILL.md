# Outcome-driven task completion

## Overview
A technique where users provide an AI agent with a desired outcome, and the agent autonomously plans and executes multiple steps to achieve it, rather than requiring step-by-step instructions.

**Use case:** Automating complex, multi-step computer tasks by specifying the end goal.
