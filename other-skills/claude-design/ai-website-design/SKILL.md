# AI-powered Website Design

## Overview
Utilizing AI tools to generate website designs, wireframes, and high-fidelity mockups based on textual descriptions, existing brand assets, and content.

**Use case:** Rapid prototyping, generating design variations, creating websites without coding knowledge.

## Key steps
1. Feed in current website, logos, and brand information to establish a design system.
2. Describe desired website features and content to generate initial wireframes.
3. Paste existing website content for AI to adapt.
4. Use the web capture tool to snapshot elements from current or competitor websites for inspiration/integration.
5. Refine designs by directly editing elements, adjusting spacing, coloring, and typography.
6. Add inline comments for specific changes or feature requests.
