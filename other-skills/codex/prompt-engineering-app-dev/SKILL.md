# Prompt Engineering for App Development

## Overview
Crafting precise and detailed instructions for AI coding agents to generate specific application features, designs, or entire apps.

**Use case:** Generating initial app structure, adding new features, refining UI/UX elements.

## Key steps
1. Provide visual references (screenshots).
2. Clearly define concept, tech stack, and core requirements.
3. Specify desired UI elements and interactions.
4. Break down complex features into smaller prompts.
