# Task Management with AI Agents

## Overview
Leveraging AI agents with a structured task management system to define and iterate through specific procedures for achieving long-term goals, providing granular control over the agent's decision-making process.

**Use case:** Automating complex, multi-step projects by guiding AI agents through predefined tasks, ensuring precise execution and continuous progress towards a goal.

## Key steps
1. Define the procedure for the agent to iterate through tasks within the /goal command.
2. Specify tasks granularly to control the duration and steps of the AI agent's loop.
3. Utilize external task management systems (e.g., Linear, Notion, markdown files) to structure tasks for the agent.
