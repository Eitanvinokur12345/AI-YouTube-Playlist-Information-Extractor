# Building an Agentic CRM

## Overview
The process of creating a CRM system that leverages AI agents to automate tasks, manage interactions, and provide insights for business and personal use.

**Use case:** Automating customer relationship management, personal productivity, business operations.

## Key steps
1. Identify all input surfaces (Slack, Gmail, custom software) where you interact with people.
2. Choose an agentic tool (e.g., Claude Code, Codex, custom system).
3. Connect external services to the agentic tool via an MCP server or CLI tool.
4. Create a custom CRM to pull and store data with centralized IDs for each person.
5. Store meeting transcripts, email histories, and chat histories in a structured database.
6. Use the stored data to prepare for future interactions and track action items.
7. Connect actionable deliverables to AI automations for automatic execution and creation.
