# Gemini to Magnific Cinematic Social Video Workflow

## Overview
This two-step workflow generates viral-style "follower flex" cinematic social media videos by combining Gemini's image generation with Magnific's animation. Gemini creates a stylized cinematic portrait with a custom follower count overlay, which is then animated into a vertical video using Magnific's motion prompts.

## Key Techniques
- Upload personal photos to Gemini with a strong cinematic prompt to create a stylized version.
- Customize the follower count overlay (1K, 10K, 100K, or custom value) directly in the Gemini prompt.
- Import the generated image into Magnific, add a motion prompt, and generate the animation as a vertical video.

## How to Apply
1. Open Gemini and upload 1–3 photos of yourself.
2. Write a cinematic prompt: "Create a stylized cinematic version of this person in [style]. Add a follower count badge showing [X]K."
3. Download the generated image.
4. Upload to Magnific and select animation/video mode.
5. Add a motion prompt describing the desired movement (e.g., "slow zoom in, cinematic camera movement").
6. Generate and export as a vertical MP4 for Instagram Reels, TikTok, or Shorts.

## Examples
- A creator uploads selfie photos, Gemini generates a dramatic cinematic portrait with "100K followers" badge, Magnific animates it with a slow-zoom effect into a 9:16 Reel.
- Custom follower counts can show milestones (10K, 100K, 1M) to celebrate growth or create aspirational content.
