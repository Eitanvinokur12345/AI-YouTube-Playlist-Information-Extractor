# NotebookLM as Zero-Setup Agent Knowledge Base

## Overview
Use Google NotebookLM as a ready-made vector-database knowledge base for AI agents — no RAG pipeline, no Supabase vector DB, no embeddings setup required. Upload documents once and agents can synthesize across them instantly, handling 99% of agent memory use cases.

**Use case:** Giving AI agents access to a searchable, multi-document knowledge base without infrastructure setup

## Key steps
1. NotebookLM handles multi-document synthesis natively — no custom RAG needed for most agent memory tasks
2. Skip Supabase vector DB for simple knowledge-retrieval agents: NotebookLM is faster to set up
3. Works best when documents are structured sources (PDFs, notes, docs) rather than raw web data
