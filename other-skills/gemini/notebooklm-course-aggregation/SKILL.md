# NotebookLM Multi-Video Course Aggregation

## Overview
Import an entire YouTube course into NotebookLM to enable cross-video Q&A and instant topic search. Demonstrated with Stanford's 25-video, ~50-hour AI course—freely available on YouTube.

## Key Techniques
- Import all course videos by YouTube URL into a single NotebookLM notebook
- Query across all lectures with natural language questions
- Use chain-of-thought prompts for complex cross-video reasoning
- Extract key lessons: use different models for different goals, focus on AI systems not individual models, chain-of-thought for complex tasks, give examples instead of instructions

## How to Apply
1. Find the YouTube playlist for the course
2. Copy each video URL into NotebookLM as a source
3. Once all videos are imported, ask cross-video questions (e.g., 'What does the course say about AI hallucination?')
4. Use the Audio Overview feature for a condensed podcast-style summary

## Examples
Stanford's ~50-hour AI course was imported into NotebookLM, transforming 25 separate lectures into a single queryable database covering beginner to AI engineer content.
