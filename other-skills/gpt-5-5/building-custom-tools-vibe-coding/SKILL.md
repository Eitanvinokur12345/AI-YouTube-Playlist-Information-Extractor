# Building Custom Tools (Vibe Coding)

## Overview
Creating software, apps, games, and other tools by describing them in natural language and receiving dynamic visual feedback, allowing for iterative development without deep technical coding knowledge.

**Use case:** Developing a private dinner booking app, solving a Rubik's Cube, creating 3D models, building a game, simulating space trajectories.

## Key steps
1. Describe desired visuals and functionality in detail.
2. Iterate by describing changes and observing the rendered output.
3. Utilize the dynamic visual rendering for rapid prototyping.
