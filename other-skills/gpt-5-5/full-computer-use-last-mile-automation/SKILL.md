# Full Computer Use / Last Mile Automation

## Overview
Taking over the computer screen to perform tasks in applications where direct API integrations or plugins are not available, effectively automating any task a human could do on a computer.

**Use case:** Reading bug reports, fixing code, creating pull requests, replying in Slack, completing spreadsheet tasks.

## Key steps
1. Grant necessary permissions for screen control.
2. Provide clear, actionable instructions for multi-application workflows.
3. Monitor its progress for complex tasks.
