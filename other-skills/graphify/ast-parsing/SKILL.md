# Abstract Syntax Tree (AST) Parsing

## Overview
Using AST libraries to parse codebases and extract structural information, representing code as a tree of nodes.

**Use case:** Creating a map of a codebase for coding assistance, code comprehension, and bug fixing without relying on LLMs for parsing.

## Key steps
1. Use ASTs for codebases as they are free and efficient for structural analysis.
2. AST calls are free, with no API calls to LLMs.
