# AI Cinematic Directing with Cinema Studio 2

## Overview
This skill covers directing AI-generated video using Cinema Studio 2's keyframe system, custom character sheets, and genre/camera presets. It replaces random generation with structured creative direction, giving filmmakers control over character consistency, emotional progression, and cinematic style.

## Key Techniques
- Define keyframes to set emotions and actions at specific points in the timeline
- Upload custom character sheets to maintain consistent character appearance across shots
- Combine Camera Mode (e.g., Handheld) with Genre Preset (e.g., Horror) to set the visual feel

## How to Apply
1. Upload custom character reference sheets for each character in your scene.
2. Set keyframes defining the emotion or action at each major beat of the video.
3. Select a Camera Mode that fits your narrative style (Handheld for tension, Cinematic for drama).
4. Apply a Genre Preset (Horror, Action, etc.) to change the overall visual atmosphere.
5. Render and review — adjust keyframe emotions or character sheets as needed.

## Examples
- Horror short film: uploaded character sheets for protagonists and antagonist, set handheld camera + horror genre preset, defined keyframes for "waking up" and "fear reaction" emotions → produced a cohesive deserted island horror clip.
