# Higgsfield Adobe Video Editing Plugin

## Overview
This skill uses the Higgsfield AI Adobe plugin to apply AI-powered video edits directly inside Adobe Premiere or After Effects. The plugin enables scene replacement, asset updates, and error correction without any reshooting, keeping the workflow entirely within the editor's existing timeline.

## Key Techniques
- Install the Higgsfield plugin from higgsfield.ai/plugin into Adobe Premiere/After Effects
- Select the clip to modify and describe the change needed (scene, asset, error fix)
- Higgsfield generates the replacement and drops it in without timeline disruption

## How to Apply
1. Download the Higgsfield Adobe Plugin from `higgsfield.ai/plugin`.
2. Install and authenticate within Adobe Premiere Pro or After Effects.
3. Select the clip or segment that needs updating.
4. Use the plugin panel to describe the change: "Replace background with city street", "Update logo to new brand version", or "Remove the mic visible in frame."
5. Review the AI-generated replacement and apply.

## Examples
- Client rebrands mid-campaign → use plugin to swap logo across all footage in hours instead of scheduling a reshoot.
- Accidentally captured a boom mic → use plugin to remove the mic from the offending frames.
