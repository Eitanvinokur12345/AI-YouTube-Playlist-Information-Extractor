# Indirect Prompt Injection

## Overview
A specific type of prompt injection where malicious instructions are embedded within a document or external data that an LLM processes, rather than directly in the user's prompt.

**Use case:** Exploiting or defending against LLM vulnerabilities, especially when processing external documents.
