# Prompt Engineering for Agentic Video Creation

## Overview
Crafting specific prompts and rules for AI agents to ensure cinematic quality, character consistency, and desired visual styles in video generation.

**Use case:** Setting up a project with a 'Master Prompt' to define video resolution, character consistency methods, image generation rules, and video prompting style for consistent outputs.

## Key steps
1. Always generate videos at 1080p resolution using Kling 3.0 as the default video model.
2. For character consistency, use an image with the character and refer to identity-preserving features, preferring 'start_frame' keyframes.
3. For image generation, use Nano Banana Pro 2 with realism directives like shallow depth of field, muted cool colors, directional lighting, and film grain.
4. Keep video prompts short (1-2 sentences) focusing on main changes for smoother motion.
