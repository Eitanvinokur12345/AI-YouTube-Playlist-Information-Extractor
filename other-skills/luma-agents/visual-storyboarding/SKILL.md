# Visual Storyboarding

## Overview
Generating high-quality visual storyboards automatically from simple inputs like reference images and story descriptions.

**Use case:** Rapidly prototyping visual narratives for video projects, allowing for quick iteration and refinement.

## Key steps
1. Provide a single character image and a reference photo to establish core elements.
2. Describe the desired story in words to generate an entire visual storyboard.
