# ChatGPT Prompt Modifier Keywords

## Overview
A small set of keyword conventions pasted before or after any ChatGPT prompt to change how it
responds, without needing to write out full instructions every time.

## Key Techniques
- `/truth` — stop ChatGPT from guessing or fabricating; answer only what's actually true.
- `/blueprint` — after stating a goal, get a full step-by-step plan to reach it.
- `/gaps` — surface important questions you forgot to ask but should have.
- `/rank` — rate every option against the others and name the single best one.
- `/pushback` — stop ChatGPT from agreeing by default and get genuine pushback on your ideas.

## How to Apply
1. Write your normal prompt or goal.
2. Append (or prepend) one of the five keywords depending on what you need: accuracy,
   planning, gap-finding, ranking, or critical pushback.
3. Note these are prompt-text conventions you type, not a recognized ChatGPT platform
   feature — they work because the model follows the instruction, not because `/truth` etc.
   are registered commands.

## Examples
Pairing `/blueprint` after a goal ("launch a newsletter" + `/blueprint`) returns a full
step-by-step plan; pairing `/pushback` after a proposal returns genuine critique instead of
agreement, directly countering AI's tendency toward sycophantic responses.
