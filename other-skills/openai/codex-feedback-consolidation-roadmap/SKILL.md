# Feedback Consolidation & Roadmap Prioritization via Codex

## Overview
A workflow for product builders that uses Codex, running inside the ChatGPT desktop app, to
pull together feedback scattered across multiple channels and turn it into a prioritized
build queue in one prompt.

## Key Techniques
- Point Codex at every feedback source at once (feedback board, app store reviews, customer
  emails) instead of triaging each channel manually.
- Ask it to rank the consolidated feedback by estimated ROI.
- Once a target feature is chosen, start a fresh Codex thread dedicated to building it.

## How to Apply
1. Open the ChatGPT desktop app and start a Codex session.
2. In one prompt, ask Codex to consolidate feedback across your feedback board, app store,
   and customer emails, and rank items by ROI.
3. Review the ranked list and pick the top item.
4. Start a new Codex thread scoped to building that feature, keeping the roadmap thread
   separate from the build thread.
