# Free AI API Key Sourcing (Google AI Studio + OpenRouter + Groq)

## Overview
A workflow for building AI apps/agents without paying for API access: use Google AI Studio for free Gemini API keys, OpenRouter for a single unified API to free models (DeepSeek, Qwen, Kimi), and Groq Cloud for very fast free inference across 50+ open-source models.

**Use case:** Prototyping or running AI software, automation, and agents without monthly API bills.

## Key steps
1. Use Google AI Studio for free Gemini API keys.
2. Use OpenRouter for one unified free API across DeepSeek, Qwen, and Kimi.
3. Use Groq Cloud when inference speed matters — it offers free access to 50+ open-source models with very fast inference.
