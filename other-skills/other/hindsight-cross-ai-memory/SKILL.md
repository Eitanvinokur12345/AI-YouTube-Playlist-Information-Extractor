# Cross-AI Unified Memory with Hindsight MCP

## Overview
Connect Claude, ChatGPT, Gemini, and Claude Code to a single Hindsight MCP memory database. Use retain to store context, recall to pull it into any session, and reflect to synthesize across everything saved — eliminating the ten-silo memory fragmentation problem.

**Use case:** Maintaining one persistent knowledge base across multiple AI tools without exporting and reimporting memory between apps

## Key steps
1. Hindsight can run as local database if you prefer not to use cloud storage
2. Use the reflect operation to synthesize across all saved memories, not just recall individual facts
3. Point Claude Code, Claude Chat, ChatGPT, and Gemini at the same MCP endpoint
