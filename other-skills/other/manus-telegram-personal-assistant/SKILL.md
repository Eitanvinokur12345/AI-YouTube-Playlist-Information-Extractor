# Telegram-Connected Manus AI Personal Assistant

## Overview
Connect Manus AI to Telegram to create a mobile-accessible personal assistant agent that receives voice, text, and image inputs from a phone and proactively suggests daily priorities by reviewing calendar, email, and goals each morning.

## Key Techniques
- Configure Manus to proactively suggest tasks each morning rather than waiting for prompts.
- Use voice mode in Telegram for fast delegation while commuting or between meetings.

## How to Apply
Having an always-available AI agent on mobile that proactively surfaces daily high-leverage tasks.

From the source video: Daily morning briefing with suggested agent tasks plus interactive mobile interface for on-the-go delegation.
