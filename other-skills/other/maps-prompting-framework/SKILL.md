# MAPS Prompting Framework

## Overview
The MAPS framework is a four-element structure for composing high-quality AI prompts that applies across all AI tools. By covering Mission (desired outcome), Ask (specific request), Parameters (context/files/constraints), and Shape (output format and tone), it consistently produces better AI responses than ad-hoc prompting.

## Key Techniques
- **Mission**: Start with the desired outcome or goal, not just what you need — e.g., "I want to grow my business."
- **Ask**: State exactly what you want the AI to do or produce.
- **Parameters**: Supply all relevant context — documents, folders, business details, constraints.
- **Shape**: Define the output format and style — bullet points, numbered list, concise/direct, tone preference.

## How to Apply
1. Before prompting, identify your *desired outcome* (Mission) rather than framing the need.
2. State the explicit *Ask* — what action should the AI take?
3. Attach or describe all *Parameters* — files, background info, scope limits, version, audience.
4. Specify the *Shape* — format (bullet list, table, prose), length, tone (direct, empathetic, formal).
5. Combine all four into a single prompt before submitting.

## Examples
- Mission: "I want to reduce customer churn." Ask: "Write a 3-email re-engagement sequence." Parameters: "Here is our product overview doc and past campaign data." Shape: "Three emails, each under 150 words, friendly but direct."
- Mission: "I want to ship this feature faster." Ask: "Review this code for bugs and suggest refactors." Parameters: "Attached: codebase folder." Shape: "Numbered list, concise, no prose explanations."
