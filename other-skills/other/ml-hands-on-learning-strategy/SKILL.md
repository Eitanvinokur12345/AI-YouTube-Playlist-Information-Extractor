# ML Hands-On Learning Strategy (70/30 Rule)

## Overview
The 70/30 rule for AI/ML learning: spend 70% of your time building real projects and 30% on theory and courses. Most beginners do the reverse, which leads to tutorial hopping without any demonstrable skills.

## Key Techniques
- Allocate 70% of learning time to building and 30% to studying
- Learn in public: post every project to GitHub and write about it on LinkedIn
- Pick one structured course and finish it before switching

## How to Apply
1. Choose one structured ML/AI course or resource.
2. For every hour of theory, spend two hours building a related project.
3. Push each project to GitHub with a clear README.
4. Write a short LinkedIn post describing what you built and what you learned.
5. Repeat the loop: theory → build → publish.

## Examples
- Building a complete ML classifier project and posting it to GitHub after studying the concept
- Writing a LinkedIn article about your first model deployment to attract recruiter attention
