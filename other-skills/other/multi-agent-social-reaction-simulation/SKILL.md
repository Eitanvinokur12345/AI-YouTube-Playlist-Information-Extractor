# Multi-Agent Social Reaction Simulation

## Overview
Uses hundreds of AI agents with distinct personalities and memories to simulate how a large population would react to any document (press release, policy, earnings report). Builds a knowledge graph from the document and runs agents in real time.

**Use case:** PR crisis testing, policy analysis, prediction market research, and trading signal generation

## Key steps
1. Upload press releases or policy drafts to Mirofish to simulate public reactions before publishing.
2. Run Mirofish Offline for fully local English-language simulations.
