# NVIDIA Free OpenAI-Compatible API Integration

## Overview
Use NVIDIA's free inference API (integrate.api.nvidia.com/v1) to access 80+ top AI models with no credit card, plugging directly into any OpenAI-compatible tool. Simply set the base URL and paste your free NVIDIA key to route your AI coding tools and agents through NVIDIA's hosted models.

**Use case:** Replace paid AI API subscriptions by routing Cursor, Zed, OpenCode, or custom agents through NVIDIA's free-tier OpenAI-compatible endpoint.

## Key steps
1. Set base URL to integrate.api.nvidia.com/v1 in your tool's API settings
2. No credit card required — get a free key from build.nvidia.com
3. Works as a drop-in replacement for OpenAI API in any compatible tool
