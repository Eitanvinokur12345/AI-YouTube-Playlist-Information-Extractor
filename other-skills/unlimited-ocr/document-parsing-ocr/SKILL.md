# Document Parsing with OCR

## Overview
Utilizing Optical Character Recognition (OCR) technology to extract text, tables, and headings from scanned documents, including multi-page PDFs, while maintaining document structure and context.

**Use case:** Automating data extraction from contracts, research papers, and other long-form documents; building search engines for document repositories.

## Key steps
1. Leverage models like Unlimited-OCR for long-horizon parsing to avoid memory loss and context fragmentation.
2. Prioritize open-source, locally runnable models for data privacy and cost efficiency.
