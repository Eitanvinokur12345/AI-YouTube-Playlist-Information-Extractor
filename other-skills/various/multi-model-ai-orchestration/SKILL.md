# Multi-model AI Orchestration

## Overview
Designing and implementing workflows that leverage multiple AI models, each specialized for different stages of a task (e.g., cheap model for reading, powerful model for judgment, execution model for action).

**Use case:** Running a business efficiently by optimizing AI costs and performance.

## Key steps
1. Use cheaper models for 'grunt work' like reading and summarization.
2. Reserve powerful, expensive models for critical judgment and strategic decisions.
3. Delegate execution to specialized agents.
