# Agent Instruction via Markdown

## Overview
A method for providing AI agents with instructions, workflows, or checklists using a plain text markdown file. The agent reads, interprets, and can directly edit and 'ship' changes within the same context (e.g., a pull request), without requiring a separate deployment process. This approach is suitable for tasks where the model's interpretative capabilities are sufficient and trust in its execution of instructions is high.

**Use case:** Defining release checklists, outlining workflows, providing general instructions, managing tasks that are not critically deterministic.

## Key steps
1. Prefer skills for tasks that involve instructions, workflows, or checklists where the AI model's understanding and direct editing capabilities are beneficial.
2. Leverage markdown's simplicity for quick iteration and agent-driven modifications.
3. Avoid skills for tasks requiring deterministic execution or high-stakes operations.
