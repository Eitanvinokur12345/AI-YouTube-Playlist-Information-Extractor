# Agentic Coding Harness Selection Framework

## Overview
A practitioner's tier-list from James Goldbach ranking every agentic coding harness by real-world experience. Claude Code and OpenAI Codex lead at S-tier; Hermes and Pi deliver in specialized use cases; OpenClaw is D-tier due to instability.

## Key Techniques
- S-tier: Claude Code (unbeatable ecosystem), OpenAI Codex (best plan-implement-review loop)
- A-tier: Hermes (24/7 always-on business agent)
- B-tier: Pi (rock solid, minimal memory), OpenCode (open-source, data privacy)
- D-tier: OpenClaw (breaks every update, 'slop factory' codebase)

## How to Apply
1. Define your use case: interactive session coding, 24/7 business automation, open-source privacy, or plan-implement-review
2. Session coding + ecosystem → Claude Code
3. Full plan-implement-review → OpenAI Codex
4. 24/7 business agent → Hermes
5. Open-source + data privacy → OpenCode
6. Avoid OpenClaw for production

## Examples
James Goldbach's personal ranking after using all harnesses: Codex is his daily driver for the full loop; Claude Code wins on ecosystem; Pi never breaks; OpenClaw breaks on every release.
