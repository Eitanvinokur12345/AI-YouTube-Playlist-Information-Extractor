# AI Coding Accuracy Improvement

## Overview
Techniques and strategies to enhance the accuracy and quality of code generated by AI models, specifically by applying structured thinking and execution principles.

**Use case:** Improving AI-generated code accuracy from 65% to 94% using a 65-line guide.

## Key steps
1. Think before coding: state your assumptions, ask when unsure, never guess.
2. Simplicity first: write the minimum code that solves the problem, no abstractions nobody asked for.
3. Surgical changes: don't touch code unrelated to the request; every changed line must trace back to what was asked.
4. Goal-driven execution: turn vague instructions into verifiable success criteria before writing a single line.
