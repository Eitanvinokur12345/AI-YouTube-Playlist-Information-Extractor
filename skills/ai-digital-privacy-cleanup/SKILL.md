# AI Digital Privacy Cleanup

## Overview
This skill uses Claude to automate the submission of CCPA opt-out requests to 47+ data brokers in a single session. It converts a multi-hour manual compliance task into a fast, AI-directed batch process.

## Key Techniques
- Provide Claude your personal details (name, address, email) and ask it to generate opt-out request emails for each data broker
- Use Claude's ability to follow structured templates across many targets in one session
- Chain requests systematically to cover all major data broker categories (marketing, people-search, analytics)

## How to Apply
1. List the data brokers you want to opt out from (or ask Claude to suggest the top 47).
2. Provide your personal information as context.
3. Ask Claude to generate and format an opt-out request for each broker.
4. Use Claude to send or schedule the emails if connected to an email tool.
5. Track completion with a checklist Claude maintains in the session.

## Examples
- Using Claude to batch-generate 47 CCPA opt-out emails in one session, saving multiple hours of manual form-filling.
- Automating annual privacy maintenance with a saved prompt that resubmits requests each year.
