# AI-Driven Design to Code Workflow

## Overview
Use Claude Design to create high-fidelity UI prototypes via voice dictation, export HTML, then import that HTML into Codex to convert the design into a fully functional app.

**Use case:** Rapidly prototype and build AI-powered websites or apps without deep technical or coding expertise.

## Key steps
1. Use voice dictation in Claude Design to quickly generate UI designs without technical jargon.
2. Export HTML from Claude Design to preserve design fidelity.
3. Paste both the exported HTML and original design prompt into Codex to generate working app code.
4. Leverage Codex connected to ChatGPT with a paid plan for best results.
