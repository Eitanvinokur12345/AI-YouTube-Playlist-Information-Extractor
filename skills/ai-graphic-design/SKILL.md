# AI-powered graphic design

## Overview
Generating visual designs like social media posts, carousels, posters, and banners using AI tools like Claude integrated with design platforms like Canva.

**Use case:** Quickly create branded visual content for social media and marketing campaigns.

## Key steps
1. Connect Claude to Canva via the 'Connectors' menu.
2. Use specific prompts like 'Use canva generate me instagram posts for my brand [brand name]' to initiate design creation.
3. Refine generated designs directly in Canva for precise branding and content adjustments.
