# AI Guardrail Documentation

## Overview
Creating and maintaining a dedicated markdown document (guardrails.md) to define explicit rules and constraints for an AI agent's behavior.

**Use case:** Preventing AI from performing unwanted actions or misbehaving by providing clear guidelines.

## Key steps
1. Create a guardrails.md file for each project.
2. Add new rules to guardrails.md whenever Claude Code misbehaves.
