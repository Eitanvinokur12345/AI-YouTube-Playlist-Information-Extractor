# AI-Powered Job Search System

## Overview
A five-tool job search system that sends better applications at scale: each tool handles its specialty—ChatGPT for resumes, LoopCV for automated applications, Claude Opus 4.8 for personalized outreach, Huntr for tracking, and Interviewing.io for practice.

## Key Techniques
- ChatGPT (5.5): Build and tailor resumes per job description
- LoopCV: Automate job application submissions at scale
- Claude Opus 4.8: Personalize recruiter outreach with nuanced writing
- Huntr: Track all opportunities in a visual pipeline
- Interviewing.io: Practice with real interviewers before final rounds

## How to Apply
1. Build a master resume in ChatGPT; save variants per target role
2. Configure LoopCV with your profile to auto-apply to matching jobs
3. For priority applications, use Claude Opus 4.8 to write a personalized recruiter outreach message
4. Track all applications in Huntr's pipeline view
5. Book Interviewing.io practice sessions before key interviews

## Examples
A candidate using this system sends tailored applications to matching roles automatically while spending manual effort only on high-priority outreach and interview prep.
