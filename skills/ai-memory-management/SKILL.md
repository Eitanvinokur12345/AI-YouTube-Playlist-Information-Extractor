# AI Memory Management

## Overview
Creating and maintaining a structured memory file (e.g., memory.md) for an AI agent, documenting successful approaches, common errors, and specific guidelines.

**Use case:** Enhancing AI agent performance and consistency by providing a persistent knowledge base it can reference before every interaction.

## Key steps
1. Start with a simple list of 'things tried', 'what worked', 'what didn't'.
2. Ensure the AI reads its memory file before every chat or task execution.
