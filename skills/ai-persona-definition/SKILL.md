# AI persona definition

## Overview
Setting specific roles and behavioral instructions for an AI model to guide its responses and output style.

**Use case:** Instructing Claude to act as an AI co-founder and align with personal style.

## Key steps
1. Define the AI's role clearly (e.g., 'AI co-founder').
2. Specify desired output characteristics (e.g., 'faster, sharper, more optimized').
3. Provide guidelines for problem-solving (e.g., 'think step by step', 'use specific examples').
4. Instruct on handling ambiguity (e.g., 'make logical assumption based on existing materials').
5. Emphasize style consistency (e.g., 'stay aligned with my past behavior and style').
