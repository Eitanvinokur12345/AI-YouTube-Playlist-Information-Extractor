# AI Persona Image Pipeline for Slideshow Posts

## Overview
A two-step pipeline for building realistic personal-brand slideshow posts entirely with AI. Claude analyzes your reference photos and aesthetic images, then generates ready-to-use image prompts for GPT Image tool. For face-consistent images, you supply reference photos and a facial description.

## Key Techniques
- Gather 10–20 reference images covering your desired aesthetic (mix of person shots and environment/mood images).
- Use Claude to generate a set of image prompts — one per slide — tailored to your aesthetic and persona.
- For slides with your face: attach clear face reference photos and add a precise facial description in the prompt's face-reference section.

## How to Apply
1. Find 10–20 images matching the aesthetic and vibe you want (not all need to show a person — include environments and moods too).
2. Drop all reference images into Claude along with a prompt asking for image generation prompts for each slide.
3. Claude outputs ready-to-use prompts for GPT Image tool.
4. For slides showing your face: attach reference photos with a clear view of your face, and fill in the "face reference" section of each prompt with a short, precise description of your features.
5. Run the prompts through GPT Image tool — generate 20 images at a time.
6. Expect ~5 usable images per batch of 20; keep regenerating until you have enough high-quality shots.
7. Drop the Claude-generated outline text into each slide and publish.

## Examples
- Self-improvement slideshow: 10 slides on "One bad day is not a bad life." Claude generates 10 image prompts based on the creator's reference photos. GPT Image renders 20 images; creator picks the 10 best.
- Environment-only slides (no face): drop the prompt as-is without face references for background/mood shots.
- Viral hook sourced from Viralo: use the connector to find proven hooks (e.g., 5M views + 128k saves), then build the full AI slideshow around that hook.
