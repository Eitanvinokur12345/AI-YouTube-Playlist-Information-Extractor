# AI Project Scoping and Definition

## Overview
A three-question methodology for clearly defining the scope and objectives of an application project, especially when using AI for coding, to prevent the AI from generating irrelevant or 'rogue' outputs.

**Use case:** Planning and initiating AI-assisted software development projects.

## Key steps
1. What problem is my application going to solve? (State clearly in one sentence)
2. Who is this for? (Identify the key user, e.g., students, doctors)
3. What does 'done' mean? (Define specific completion criteria, e.g., upload a PDF for AI analysis, 100 users, fully deployed)
