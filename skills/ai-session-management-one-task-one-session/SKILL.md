# AI Session Management (One Task, One Session)

## Overview
The habit of dedicating each AI session to a single, focused task to prevent context clutter and maintain AI clarity. Avoid mixing unrelated tasks like refactoring and bug hunting in the same session.

**Use case:** Maintaining AI clarity and efficiency, preventing AI from getting confused by irrelevant past context.

## Key steps
1. Yesterday's refactor is noise in today's bug hunt.
2. Start with a clean slate for sharp answers.
