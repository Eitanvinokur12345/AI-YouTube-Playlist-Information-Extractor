# AI Session Reset (Restarting When Arguing)

## Overview
When the AI starts going in circles, repeating itself, or misunderstanding, it's more efficient to restart the session with a fresh, well-phrased prompt rather than trying to correct it repeatedly.

**Use case:** Saving time and achieving better results by avoiding unproductive loops and ensuring the AI starts with a clear understanding.

## Key steps
1. Stop correcting it when it goes in circles; restart.
2. A clean start beats a long argument.
3. A right ask, first try, saves five minutes.
