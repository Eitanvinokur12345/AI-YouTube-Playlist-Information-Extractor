# AI Skill Bundling

## Overview
Identifying recurring patterns in AI tasks and bundling them into named, scoped skills that the AI can execute on demand.

**Use case:** Automating repetitive tasks, improving efficiency, and reducing the need for constant human oversight.

## Key steps
1. Each skill should correspond to one job, be small, scoped, and named.
2. Skills can be loaded on demand and incur zero cost when idle.
