# AI Token Usage Monitoring

## Overview
The ability to track and visualize the number of input and output tokens used by AI models, along with their associated costs.

**Use case:** Understanding and optimizing the cost of AI agent interactions by monitoring token consumption.

## Key steps
1. Use tools like ccglass to get a real-time view of token usage.
2. Analyze input vs. output token ratios to identify inefficiencies.
3. Understand that you pay for what you send (input tokens), not just what the AI says (output tokens).
