# AI Website Design Polish with Claude Code

## Overview
This technique systematically improves the visual quality of AI-built websites by applying professional design principles. It focuses on intentional motion design (proper easing curves, not default transitions), typography hierarchy, and design system consistency to bridge the gap between AI output and professional-quality UI.

## Key Techniques
- Apply custom easing curves (ease-in-out, spring) instead of default CSS transitions
- Use Impeccable to audit AI-generated components against a design system
- Review typography, spacing, and color hierarchy for consistency

## How to Apply
1. Generate the initial website with Claude Code
2. Run Impeccable to identify design quality issues
3. Ask Claude Code to fix easing curves on all animated elements
4. Check typography hierarchy (font sizes, weights, line heights)
5. Verify spacing system consistency (use a base-8 or base-4 grid)
6. Test motion at different screen sizes and reduce-motion settings

## Examples
- Adding spring easing to hover states on cards instead of linear transitions
- Running Impeccable's design review to find inconsistent border-radius values
- Replacing hardcoded colors with design token references
