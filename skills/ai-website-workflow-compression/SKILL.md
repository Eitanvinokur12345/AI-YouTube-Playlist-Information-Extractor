# AI Website Workflow Compression

## Overview
This workflow combines Nano Banana Pro for photorealistic AI image generation, Claude for code and layout, and 21st.dev component libraries to build and deploy complete websites rapidly. It collapses multi-tool, multi-step processes into a single streamlined session.

## Key Techniques
- Generate site images directly in Claude chat using the Nano Banana Pro integration
- Pull UI components from 21st.dev to avoid building layouts from scratch
- Use Phygital+ to switch between 30+ AI tools within one session

## How to Apply
1. Define your website concept and gather reference images or brand assets.
2. Use Nano Banana Pro (via Claude) to generate hero images and visuals.
3. Pull appropriate UI components from 21st.dev for the layout.
4. Ask Claude to assemble the site code, referencing the generated images.
5. Deploy directly from the session output.

## Examples
- Building a product landing page with AI-generated product imagery and animated UI components in one Claude session.
- Creating a portfolio site by combining Phygital+ image tools with 21st.dev card components.
