# Analyzing story structures from reference materials

## Overview
Save transcripts of compelling stories (videos, posts) and use AI to break them down into components like hook, setup, tension, payoff, pacing, and language for study.

**Use case:** Deconstructing great storytelling to understand and replicate narrative techniques.

## Key steps
1. Focus on one element at a time (e.g., hooks) when studying
2. Compare multiple stories to identify patterns in structure
3. Use AI to generate variations of successful structures
