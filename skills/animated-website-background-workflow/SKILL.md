# Animated Website Background Workflow

## Overview
A four-step pipeline for producing a polished, animated website with no design skills: start
from a proven template prompt, generate the site with Claude Design, then replace a static
background with an AI-generated motion visual.

## Key Techniques
- Reuse a ready-made prompt from a template gallery instead of prompting a layout from scratch.
- Iterate on the generated site by only editing the parts specific to your own idea.
- Generate a still visual with an image tool, then convert it into a short looping video for
  the background.
- Ask the site builder to swap the static background for the generated video in place.

## How to Apply
1. Browse a template gallery (e.g. motionsites.ai) and pick a design you like; copy its prompt.
2. Paste the prompt into Claude Design and replace only the idea-specific parts with your own.
3. Let Claude Design build the full site layout in seconds.
4. Generate a background visual with an image tool such as Whisk + Nano Banana.
5. Turn that visual into a short video.
6. Drop the video back into Claude Design and ask it to replace the background with it.
