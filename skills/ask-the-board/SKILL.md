# Ask the Board

## Overview
Creates a board of AI-cloned expert advisors. When a question is asked, it gives each advisor's take in their own voice, flags where they agree/disagree, and synthesizes what the user should actually do.

**Use case:** Making better, more confident decisions by leveraging cloned expert opinions.
