# ATS Filtering Analysis

## Overview
Simulating an Applicant Tracking System (ATS) and hiring manager review process to identify and fix sections that would be skipped.

**Use case:** Ensuring resumes pass initial automated screening and capture human attention.

## Key steps
1. Ask Claude to act as an ATS filter and a hiring manager.
2. Request feedback on which sections would be skipped.
3. Instruct Claude to rewrite those sections to 'stop the scroll' (make them engaging).
