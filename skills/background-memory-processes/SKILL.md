# Background Memory Processes

## Overview
Automated workflows and memory injection prompts to maintain, rectify, and summarize agent memories across different sources.

**Use case:** Ensuring memory accuracy, organization, and providing relevant context at the start of new agent sessions.

## Key steps
1. Set up daily workflows to clean and rectify memory sources.
2. Use system prompts with hooks/scripts to inject summarized memory chunks (e.g., recent session transcripts, Git changes, knowledge base documents) into new sessions.
