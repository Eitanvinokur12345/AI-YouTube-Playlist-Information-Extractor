# Batch AI queries to reduce token costs

## Overview
Consolidate multiple questions into a single prompt by writing them in a notes app, then pasting as a numbered list to get answers in one API call, reducing per-request overhead and token spend.

**Use case:** Employees or developers who need to ask many small questions to an LLM and want to minimize token usage and latency.

## Key steps
1. Group related questions together
2. Use clear numbering for easy parsing
3. Specify output format (e.g., JSON, bullet points)
