# Book-to-Skill Agent Creation

## Overview
The ability to transform technical books, document folders, or collections of sources (PDF, EPUB, DOCX, MD, HTML, RTF, MOBI) into a unified agent skill for AI models. This process distills content into structured formats like frameworks, decision rules, anti-patterns, and per-chapter files, rather than just summaries, to prevent AI hallucination.

**Use case:** Creating custom knowledge bases for AI agents from existing documentation, enabling accurate referencing and study.

## Key steps
1. Point the skill at a file, folder, or glob.
2. Customize the skill's purpose (study, reference, apply frameworks, mental models).
