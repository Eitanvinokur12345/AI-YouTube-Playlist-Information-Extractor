# Career Ops: Automated Job Search with Claude Code + Playwright

## Overview
An open-source repo called Career Ops combines Claude Code, Playwright, and a set of AI skills to automate job searching at scale. It filters job listings, tailors applications to each role, and generates ATS-friendly resumes rather than blasting generic applications.

## Key Techniques
- Use Career Ops on GitHub to automate targeted job applications with Claude Code and Playwright
- The system filters roles and tailors resumes per listing rather than sending generic blasts

## How to Apply
Job seekers wanting to apply to many targeted positions without manually tailoring each application.

## Examples
Customized ATS-friendly resumes and tailored applications for matched job listings, generated automatically at scale.
