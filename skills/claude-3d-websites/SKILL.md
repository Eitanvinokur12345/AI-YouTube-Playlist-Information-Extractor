# Claude Code 3D Website Pipeline

## Overview
A pipeline for building and selling premium 3D websites: Claude Code writes the site, Nano Banana 2 generates imagery (free tier ~600-750/mo), Kling 3.0 animates start/end frames into video and Vercel deploys in one click. Runway ML or Pika can substitute for Kling if needed.

## Key Techniques
- Generate site imagery with Nano Banana 2's free tier.
- Animate hero sections with Kling 3.0 start/end frames.
- Deploy in one click from VS Code with Vercel.
