# Claude Auto-Filing Knowledge Wiki

## Overview
Pipe voice notes, saved articles, and watched videos into Claude, which automatically files each item and links it together into an Obsidian-based wiki that grows smarter over time. This eliminates manual note-taking and builds a self-organizing second brain.

## Key Techniques
- Route all content inputs (voice, text, video) through Claude for automatic categorization and filing
- Use Claude to extract key concepts and create bidirectional links in Obsidian
- Build a wiki that accumulates context over time, making future filings richer

## How to Apply
1. Set up an Obsidian vault as the destination for your knowledge base.
2. Configure Claude to receive inputs: voice note transcripts, article text, video summaries.
3. For each input, have Claude identify the topic, extract key points, find related existing notes, and create a new linked note.
4. Let the wiki grow — as more items are filed, Claude's linking becomes more valuable.

## Examples
- Record a voice note on a new AI tool → Claude files it under the right topic and links to existing notes on related tools
- Save an article → Claude extracts key insights and connects them to your previous research
- Watch a tutorial video → Claude summarizes and files the techniques alongside similar skills
