# Claude Brand Style Guide for Consistent Content

## Overview
Use Claude to generate a brand style guide PDF by filling in a prompt template with your colors, fonts, niche, and overall vibe. Attach this PDF to every subsequent Claude Design or content-generation prompt so all outputs share a consistent visual identity.

## Key Techniques
- Fill a structured prompt template (brackets = your specifics: colors, fonts, niche, vibe) to produce the full style guide.
- Save the output as a PDF and attach it to every Claude Design prompt as a context file.
- Treat the style guide as a one-time setup that pays dividends across all future content requests.

## How to Apply
1. Prompt Claude: "Create a brand style guide for my content. My colors are [X], fonts are [Y], my niche is [Z], and the overall vibe is [W]."
2. Claude generates a comprehensive style guide document.
3. Save it as a PDF.
4. Attach this PDF alongside every subsequent Claude Design prompt for motion graphics, map animations, or static visuals.
5. Update the PDF whenever your brand evolves.

## Examples
- A self-improvement content creator specifies: primary color blue, secondary gold, font Inter, niche productivity, vibe "clean and motivational." Claude outputs a full brand guide with usage rules, color codes, and typography hierarchy.
- The resulting PDF is attached to every motion graphic and slideshow prompt, ensuring all AI outputs look like they came from the same designer.
