# Claude Canva Integration Setup

## Overview
This skill connects Canva to Claude via the Connectors feature, enabling users to generate and edit Canva designs from within Claude chat. The setup takes under 30 seconds and unlocks design generation without leaving the conversation.

## Key Techniques
- Navigate to Claude Customize → Connectors → Browse Connectors to find Canva
- Click Connect and log in to your Canva account to authorize the integration
- Use natural language prompts in Claude to create, edit, or remix Canva designs in-chat

## How to Apply
1. Open Claude and go to **Customize** (top-right menu).
2. Select **Connectors** → **Browse Connectors**.
3. Find **Canva** in the list and click **Connect**.
4. Authorize with your Canva credentials.
5. Return to any Claude chat and describe the design you want — Claude will generate or edit it via Canva.

## Examples
- "Create a LinkedIn banner for a software engineer with a dark tech aesthetic"
- "Edit my Canva presentation to add a summary slide at the end"
- "Make a social media post template in Canva for product launches"
