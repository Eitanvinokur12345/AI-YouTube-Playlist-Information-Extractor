# 18-Agent Claude Code SEO Audit Workflow

## Overview
A multi-agent Claude Code plugin (25 sub-skills, 18 specialist agents run in parallel) that audits technical SEO, content quality (E-E-A-T), Schema markup, AI-search (GEO) readiness, and local SEO via `/seo audit <url>`, producing a prioritized, actionable fix list plus markdown/JSON/PDF reports.

**Use case:** Running a full-stack SEO audit covering technical issues, local search, backlinks, and GEO entirely within Claude Code.

## Key steps
1. The 18-agent SEO team is free and open-source — clone it and run it inside Claude Code.
2. Agents cover four distinct domains: technical SEO, local SEO, backlink audits, and GEO (AI-search optimization).
3. Full setup guide available via Google Doc (RANKER Guide.docx).
