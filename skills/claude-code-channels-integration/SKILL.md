# Claude Code Channels Integration

## Overview
Use the Claude Code Channels architectural feature to connect external messaging platforms (Telegram, Discord) directly to a running Claude Code session. Eliminates the need to switch to Claude interface — instruct your agent from wherever you already communicate.

## Key Techniques
- Connect Telegram or Discord to Claude Code via Channels to issue commands from your phone without opening the terminal.
- Use Channels to push notifications or task completions back to your messaging app for async agent workflows.

## How to Apply
Directing a Claude Code agent from Telegram or Discord without switching applications or context.
