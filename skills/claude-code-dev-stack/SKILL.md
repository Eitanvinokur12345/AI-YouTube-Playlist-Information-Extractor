# Claude Code Dev Stack (5 Essential Tools)

## Overview
This skill defines the five complementary tools that transform Claude Code outputs from basic prototypes into production-ready applications. Each tool solves a specific gap that Claude Code alone cannot fill.

## Key Techniques
- **Impeccable** — automated design quality feedback on Claude's UI output
- **Playwright** — browser test automation without manual test code
- **Supabase** — one-command database and authentication setup
- **GitHub** — version control and safe multi-branch iteration
- **Vercel** — instant production deployment from the terminal

## How to Apply
1. Create a GitHub repo before writing any code.
2. Initialize Supabase and connect it to your project.
3. Use Claude Code to build features iteratively.
4. Run Impeccable on generated UIs to check design quality.
5. Use Playwright to validate each feature before shipping.
6. Deploy to Vercel with a single terminal command.

## Examples
- Shipping a full-stack web app with auth, database, automated UI tests, and live deployment using only Claude Code and the 5-tool stack
- Using Playwright as Claude Code's automated test runner to validate UI on every build cycle
