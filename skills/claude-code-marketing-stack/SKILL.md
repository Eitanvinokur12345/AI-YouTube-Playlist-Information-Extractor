# Claude Code Marketing Stack (131 Skills)

## Overview
A complete go-to-market stack of 131 plug-and-play Claude Code skills covering the entire marketing workflow. Free to install, covers every marketing function from ICP research to outreach, and turns Claude Code into a full marketing department.

## Key Techniques
- SEO research and optimization skills
- Ad copy generation and campaign management
- ICP (Ideal Customer Profile) research and targeting
- Brand voice development and consistency enforcement
- Logo and image generation workflows
- Content creation pipeline (blog, social, email)
- Social media management and scheduling
- Outreach and partnership campaign skills

## How to Apply
1. Download the full stack from the Google Doc linked in the video description
2. Install the 131 skills into your Claude Code environment
3. Use each skill for its designated marketing function
4. Chain skills together for complete campaigns (research → copy → content → outreach)

## Examples
- Run ICP research skill → feed into brand voice skill → generate ad copy skill → schedule social media skill
- SEO audit skill → content brief skill → blog post creation skill
- Prospect list skill → personalized outreach skill
