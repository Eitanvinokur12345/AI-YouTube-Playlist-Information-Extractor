# The 5 Levels of Claude Code Mastery

## Overview
A structured 5-level progression framework for Claude Code users — from a basic global CLAUDE.md file to a fully autonomous 24/7 AI employee infrastructure. Most users are stuck at Level 1 without realizing it.

## Key Techniques
- **Level 1**: Global CLAUDE.md (2000+ lines), a few slash commands for daily automations
- **Level 2**: Split into project-level CLAUDE.md files (<200 lines each) with project-specific skills
- **Level 3**: MCP servers and CLI tools per project + `/schedule` cron automations
- **Level 4**: Shared knowledge base all sessions read/write + self-evolving framework + auto-PR review overnight
- **Level 5**: 24/7 system daemon managing Claude Code + Codex sessions, Telegram/Slack integration, overnight skill optimization

## How to Apply
1. Assess your level: do you have a global CLAUDE.md? Project-level files? MCP servers? A daemon?
2. Identify your current level and the single upgrade that moves you to the next
3. Level 1→2: Refactor global CLAUDE.md into project-level files under 200 lines each
4. Level 2→3: Install MCP servers for your key tools; set up `/schedule` cron workflows
5. Level 3→4: Create a shared knowledge base path all sessions can read and write to
6. Level 4→5: Write a system service that manages session lifecycle; connect to Telegram/Slack

## Examples
- A developer at Level 2 sets up a `/schedule` cron to run code reviews every night → Level 3
- Level 4: Claude Code sessions from different projects all write learnings to a shared `knowledge-base/` folder, which is included in every new session's context
- Level 5: A daemon receives "ship feature X" via Telegram → spins up a Claude Code session → implements → submits PR → sends completion message back
