# Claude Code Routines for Scheduled Automation

## Overview
Use Claude Code's built-in Routines tab to schedule prompts to fire at any time of day inside a project folder, enabling fully automated agentic workflows. Drop resources into the folder, set the routine, and Claude executes the task autonomously on schedule.

## Key Techniques
- Use the Routines tab in Claude Code to set timed prompt schedules
- Drop all necessary resources into the project folder so Claude has context when the routine fires
- Build business automations in about five minutes with no external scheduling tools

## How to Apply
1. Open Claude Code and navigate to the Routines tab.
2. Create a new routine and write the prompt you want Claude to execute.
3. Set the schedule (daily at 9am, hourly, etc.).
4. Drop any resources Claude will need (data files, templates, reference docs) into the project folder.
5. Save and activate — Claude Code will execute the prompt autonomously at the scheduled time.

## Examples
- Daily morning briefing: Claude pulls overnight data, summarizes key metrics, and posts to Slack
- Weekly competitor monitoring: Claude scans competitor sites and drafts a summary report
- Automated lead follow-up: Claude checks new leads and drafts personalized outreach each morning
