# Skill (Claude Code)

## Overview
A feature in Claude Code where Claude automatically invokes a predefined task or function based on the conversation context. Its description is always in context, and it is not free.

**Use case:** Automating repetitive tasks where Claude Code decides when to execute them.

## Key steps
1. Use skills for tasks you want Claude Code to invoke automatically.
2. Be aware that skill descriptions consume context and may incur costs.
