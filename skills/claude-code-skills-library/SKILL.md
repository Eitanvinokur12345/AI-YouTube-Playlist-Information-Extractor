# Claude Code Skills Library Usage

## Overview
Claude Code can be extended with 100,000+ installable AI Skills that turn it into a domain specialist. Skills encode proven instructions for recurring tasks, eliminating the need to re-prompt from scratch.

## Key Techniques
- Browse the Skills library for your domain (UI, SEO, testing, etc.)
- Install the skill once in Claude Code
- Claude follows proven instructions automatically every time
- Skills also work with other AI tools beyond Claude

## How to Apply
1. Visit the Claude Code Skills library (community-maintained)
2. Find a skill matching your task (e.g., 'SEO Research', 'UI Design', 'Lead Generation')
3. Install the skill per the README instructions
4. Invoke the skill in Claude Code—no long prompt needed

Installing an 'App Development' skill turned Claude Code into a repeatable specialist that follows proven app-building patterns on every invocation.
