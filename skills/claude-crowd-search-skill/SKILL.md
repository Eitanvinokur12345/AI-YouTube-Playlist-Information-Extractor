# Claude Crowd-Sourced Search Skill

## Overview
A Claude skill that aggregates top-voted content from Reddit, X, YouTube, and Polymarket into
a single search, surfacing crowd-ranked opinions and predictions rather than one source's view.

## Key Techniques
- Query multiple platforms (Reddit, X, YouTube, Polymarket) in one pass.
- Rank results by community voting/engagement rather than recency alone.
- Cross-reference qualitative sentiment (Reddit/X) against a quantitative signal
  (Polymarket's market-implied odds).

## How to Apply
1. Ask the skill to research a topic or claim.
2. Review the top-voted takes it surfaces from each platform.
3. Use Polymarket's implied odds as a sanity check against social sentiment.
