# Claude Design Motion Graphics Pipeline

## Overview
Claude Design's prototype mode generates motion-graphic animations, map animations, and static visuals directly from a video script and brand style guide PDF. Since there is no MP4 export yet, you screen-record the animation playing in a new browser tab.

## Key Techniques
- Create a brand style guide PDF in Claude first (colors, fonts, niche, vibe) and reuse it on every prompt.
- Attach screenshots of the animation style you want alongside the prompt to guide output quality.
- For static visuals, skip Claude Design — drop the script segment + brand PDF into regular Claude chat.

## How to Apply
1. Ask Claude to generate a brand style guide from your colors, fonts, niche, and vibe — save as PDF.
2. In Claude, open Claude Design → select "prototype" mode → name the project → hit Create.
3. Drop your complete prompt + brand style guide PDF + animation-style screenshots into the chat and send.
4. Wait 5–10 minutes for motion graphics (longer for map animations — they require multiple self-correction iterations).
5. To export: open the prototype in a new tab, hit Play, and screen-record the output.
6. For static visuals: drop the relevant script segment + brand PDF into a regular Claude chat — no Claude Design needed.

## Examples
- Motion graphic animation for a video intro: paste the script section, attach 3–5 style reference screenshots and the brand PDF. Claude renders a looping animation with graphics and text matching the narration.
- Map animation: drop 10+ map-style reference screenshots + the brand PDF + the destination prompt. Claude generates a complete animated map route — expect 10–15 minutes and several auto-fix iterations.
- Static explainer visual: drop the script line + brand PDF into Claude chat and get a polished slide in under 2 minutes.
