# Claude Marketing Skills Library (29 Skills)

## Overview
A free library of 29 Claude skill files covering ad creatives, copywriting, email sequences, content strategies, and other marketing functions. Each skill installs in 60 seconds and transforms Claude into a structured, domain-specific marketing expert.

## Key Techniques
- Download raw skill files from the public library and upload under Claude Capabilities
- Once installed, Claude automatically applies the skill to every relevant marketing query
- Skills deliver structured, role-specific outputs like an agency would

## How to Apply
1. Search "Marketing Skills Claude" to find the skill library (Claude Skills Marketplace or GitHub).
2. Download the raw markdown file for the skill you want (e.g., Ad Creative Writer, Email Sequence Builder).
3. In Claude, go to Settings → Capabilities → Upload Skill File.
4. Start a new chat. Claude will automatically detect and apply the skill when relevant.
5. For a specific marketing task, start your prompt with the task type: "Write a 5-email welcome sequence for [product]."

## Examples
- Install the "Ad Creative Writer" skill and ask Claude to write 5 Facebook ad variations for a product launch.
- Install the "Content Strategy" skill and ask Claude to build a 30-day content calendar for a B2B SaaS company.
