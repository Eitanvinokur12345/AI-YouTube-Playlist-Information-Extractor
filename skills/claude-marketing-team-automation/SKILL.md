# Claude Marketing Team Automation

## Overview
Build a set of Claude Code AI skills that replace core marketing team functions including competitor research, top-performing ad analysis, strategy building, and campaign optimization. Each skill runs as a modular unit that can operate independently or be chained into a 24/7 automated marketing operation.

## Key Techniques
- Create dedicated Claude Code skills for each marketing function (research, analysis, strategy, optimization)
- Chain individual marketing skills into a continuous automated workflow
- Run marketing operations 24/7 without human intervention using modular skill architecture

## How to Apply
1. Identify the core marketing functions you want to automate (competitor research, ad analysis, strategy, optimization).
2. Build a separate Claude Code skill file for each function with clear input/output definitions.
3. Test each skill individually to verify quality.
4. Chain the skills together in sequence or run them in parallel as your automated marketing stack.
5. Schedule the stack to run at regular intervals for continuous 24/7 operation.

## Examples
- A competitor research skill that monitors rival ad creative and reports weekly
- An ad analysis skill that scores top-performing ads and extracts patterns
- A strategy-building skill that synthesizes research into a marketing plan
- An optimization skill that recommends budget adjustments based on performance data
