# Claude Master Statement Memory Technique

## Overview
Claude forgets who you are with every new chat. The Master Statement technique fixes this by creating a one-time personal profile that you paste at the start of any conversation. Claude conducts the profile interview and writes the document for you — no coding required.

## Key Techniques
- Have Claude interview you in a single conversation covering learning style, skills, goals, and current projects
- Save the resulting profile as a reusable document (PDF or markdown)
- Paste or upload the document at the start of every new chat

## How to Apply
1. Start a new Claude chat and say: "I want to create a Master Statement. Interview me so you can build a complete profile of who I am and what I'm working on."
2. Answer Claude's follow-up questions for 20–45 minutes to build a rich profile.
3. Ask Claude to write the final Master Statement as a compact document.
4. Save it. At the start of every new chat, paste or upload the Master Statement.

## Examples
- A freelance designer uses their Master Statement to give Claude instant context about their clients, preferred stack, and writing voice so every new chat delivers relevant output.
- A startup founder pastes their Master Statement when switching between Claude, ChatGPT, and Gemini so no tool ever starts from zero.
