# Claude Code MCP Power Stack

## Overview
A set of five MCP servers that supercharge Claude Code: Perplexity (live web), Playwright (browser automation), Firecrawl (site crawling for RAG), Glyph (image/video model access) and Chrome (control your open browser). Together they give Claude Code real-time internet, browser control and media generation.

## Key Techniques
- Add Perplexity MCP for live internet access while coding.
- Use Playwright MCP so Claude can drive a browser, run tests and upload files.
- Firecrawl MCP crawls whole sites into context for RAG.
