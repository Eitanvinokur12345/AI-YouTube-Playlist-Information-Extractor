# Claude Power User Prompt Codes

## Overview
Five hidden Claude prompt codes that activate distinct high-performance output modes. Apply them as simple prefixes or suffixes to any prompt — no system prompt engineering required.

## Key Techniques
- **L99** — Stops Claude from hedging; produces expert-level analytical depth
- **/ghost** — Strips all AI writing tells; output reads as natural human writing
- **OODA** — Applies a military Observe-Orient-Decide-Act decision framework
- **Scaffold** — Converts any project into a complete ordered step-by-step action plan
- **Ultra think** — Activates maximum reasoning mode for 10× deeper analysis

## How to Apply
- Append L99 at the end of analytical questions: "Analyze this market. L99"
- Append /ghost after any writing task: "Write this email. /ghost"
- Prepend OODA for decisions: "OODA: Should I pivot my product?"
- Prepend Scaffold for planning: "Scaffold: Build a mobile app in 30 days"
- Prepend Ultra think for deep problems: "Ultra think: What's wrong with this architecture?"

## Examples
- "Write a LinkedIn post about AI trends. /ghost" → removes all AI tells
- "OODA: Should I hire a developer or use Claude Code?" → structured decision output
- "Scaffold: Launch a newsletter in 2 weeks" → complete ordered action plan
