# Claude Record a Skill (Desktop Action Capture)

## Overview
The Claude desktop app can capture a live demonstration of clicks, typing, and spoken narration, then package that sequence into a reusable Skill. This turns a one-off manual routine into a repeatable automation without any scripting.

## Key Techniques
- Record the target workflow end-to-end in a single pass, narrating intent by voice as you act.
- Keep the recorded task simple and linear (repetitive admin work) rather than branching/conditional.
- Save the resulting Skill and re-run it whenever the same task recurs.

## How to Apply
1. Open the Claude desktop app and start a Skill recording.
2. Perform the desktop task normally — click, type, and narrate out loud what each step accomplishes.
3. Stop the recording; Claude turns the captured sequence into a Skill.
4. Replay the Skill on future occurrences of the same task instead of repeating it by hand.

## Examples
The source video frames this for repetitive admin work — e.g. a recurring multi-step data-entry or form-filling routine — recorded once and replayed on demand.
