# Claude Role-Specific Skills Library

## Overview
A free library of 300 Claude skills, each encoding a specific business role's workflows, constraints, and output formats. Dropping a skill into Claude gives it the knowledge and behavior of a trained employee in that role—financial analyst, campaign planner, HR manager, and more—without any prompt engineering.

## Key Techniques
- Install role skills via Claude's skill library (settings > skills)
- Combine multiple role skills for cross-functional tasks
- Browse skills by department to find the right role quickly

## How to Apply
1. Access the free 300-skill library (linked in the video description)
2. Browse skills by business role or department
3. Install the relevant skill in Claude
4. Assign tasks as if you're briefing an employee in that role
5. Claude will respond using the role's domain knowledge, format, and constraints

## Examples
- Installing the "Financial Analyst" skill to get structured DCF models from Claude
- Using the "Campaign Planner" skill to produce media mix plans with budget breakdowns
