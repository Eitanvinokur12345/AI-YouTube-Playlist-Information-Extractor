# Claude Self-Improvement Skill Pack

## Overview
Six Claude skills that make Claude projects self-improving: a web scraper (using Exa semantic search), an 'ingest source' knowledge-base builder, an 'improve system' skill with five modes (audit, skill review, experience, historical review, foundation), an 'ask the board' panel of cloned experts (/asktheboard) and an internal focus group. Together they let a Claude project audit and upgrade itself.

## Key Techniques
- Use the 'improve system' skill's audit mode to find weak skills.
- Clone domain experts into 'ask the board' and consult them with /asktheboard.
- Use Exa semantic search inside the web-scraper skill for better sources.
