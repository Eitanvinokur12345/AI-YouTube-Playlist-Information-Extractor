# Claude Code Skills Leaderboard Discovery

## Overview
Use the Claude Code skills leaderboard (ranking 90,000+ skills) to discover the best skill for any task by copy-pasting the rankings directly into Claude Code and asking which one to install.

**Use case:** When you need a Claude Code skill for a specific task but don't know which of the thousands available is highest quality — let the leaderboard and Claude guide the selection.

## Key steps
1. Select all and copy the entire Claude Code skills leaderboard page, then paste into Claude Code with your task description
2. Ask Claude 'which of these skills should I get for [my task]?' to get a ranked recommendation
3. The leaderboard ranks 90k+ skills — using it prevents installing low-quality skills when better alternatives exist
