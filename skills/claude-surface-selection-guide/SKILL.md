# Claude Surface Selection Guide (Chat vs Code vs Cowork)

## Overview
Anthropic's three Claude surfaces each have distinct strengths. Using the wrong one wastes tokens and slows you down — Claude Chat for building, or Claude Code for brainstorming, both produce worse results than matching the surface to the task type.

## Key Techniques
- **Claude Chat**: Conversational, ephemeral, great for exploration and writing
- **Claude Code**: Agentic, tool-calling, great for execution and building
- **Claude Cowork**: Persistent, team-shareable, great for recurring workflows and shared tooling

## How to Apply
Choose the surface based on what you're doing:

**Use Claude Chat when:**
- Brainstorming new ideas or directions
- Writing emails, proposals, or documents
- Turning a messy concept into a clean plan
- Understanding something complicated (explain mode)

**Use Claude Code when:**
- Building an app, website, or automation
- Running agentic tasks with tool calls (browser, files, APIs)
- Deploying code to production
- Any task where Claude needs to take actions, not just respond

**Use Claude Cowork when:**
- Sharing Claude access across a team
- Running persistent tools that multiple people use
- Setting up collaborative AI workflows
- Deploying agent-as-a-service for your organization

## Examples
- "I want to brainstorm a new product idea" → Claude Chat
- "I want to build the landing page for that product" → Claude Code
- "I want my whole marketing team to use the same AI workflow" → Claude Cowork
