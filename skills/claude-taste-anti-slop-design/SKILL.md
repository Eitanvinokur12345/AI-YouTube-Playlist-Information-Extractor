# Claude Taste Skill — Anti-Slop Frontend Design

## Overview
The 'Taste' Claude skill enforces design aesthetics and prevents the generic AI-generated "slop" look in frontend work. It integrates with ChatGPT's image generation model to create images that visually fit the design context.

## Key Techniques
- Applies curated aesthetic principles to Claude's frontend code generation
- Integrates with ChatGPT's image tool for contextually matching image generation
- Acts as an anti-slop quality gate during frontend development

## How to Apply
1. Install the Taste skill in Claude Code
2. Start your frontend build as normal
3. The skill enforces aesthetic standards on generated components
4. Use the ChatGPT image integration to generate images that fit your visual direction

## Examples
- Building a landing page: Taste prevents cookie-cutter layouts and generates brand-fitting hero images
- Dashboard UI: ensures visual cohesion across component styles
