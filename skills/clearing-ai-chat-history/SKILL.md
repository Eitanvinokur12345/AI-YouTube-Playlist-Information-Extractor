# Clearing AI chat history

## Overview
Regularly clearing the chat history in Claude to reset the conversational context, which helps in managing token usage and reducing costs.

**Use case:** Optimizing AI interaction costs and ensuring a fresh, unbiased context for new tasks, preventing the AI from being influenced by previous, irrelevant conversations.

## Key steps
1. Use the /clear command in Claude to reset the chat and manage token usage effectively.
