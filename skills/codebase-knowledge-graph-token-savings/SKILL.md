# Codebase Knowledge Graph for Claude Code Token Savings

## Overview
Build a queryable code graph (using a tool like Graphify) that lets Claude Code answer codebase questions without re-scanning every file on each query. The graph maps relationships between files, functions, and modules so Claude can look up context efficiently.

**Use case:** Reducing token consumption in long Claude Code sessions on large codebases by pre-indexing the codebase into a queryable graph.

## Key steps
1. Use a queryable code graph (like Graphify) with Claude Code to avoid re-reading files on every query.
2. Pre-index your codebase into a knowledge graph to dramatically reduce token usage in Claude Code sessions.
