# Composio

## Overview
A tool that acts as a universal connector for AI agents, allowing Claude Code to interact with thousands of different applications through a single integration. It streamlines the process of connecting multiple tools, making AI workflows more token-efficient and accurate by discovering tools on-demand.

**Use case:** Connecting various applications (Gmail, Google Drive, Notion, Slack, GitHub, etc.) to Claude Code, automating tasks across different platforms, managing multiple tool integrations without bloating Claude's context window.

## Key steps
1. Connects to thousands of apps from one dashboard.
2. More token-efficient as Claude calls Composio, which then finds and executes the correct tool.
3. Free to use with 20,000 tool calls per month.
