# Context Preservation Prompt Engineering

## Overview
Designing a specific prompt structure and set of rules for an AI to summarize its current state and context, facilitating seamless transfer to a new conversation session.

**Use case:** Creating robust prompts that enable AI models to effectively retain and transfer critical information across conversation boundaries, mitigating memory limitations.

## Key steps
1. Define clear, distinct sections within the prompt for different types of context (e.g., goal, state, next steps, issues).
2. Provide explicit rules for the AI's response, including length constraints, specificity requirements, and content inclusion/exclusion.
3. Specify the desired output format, such as a fenced code block, to enable easy copying and pasting.
