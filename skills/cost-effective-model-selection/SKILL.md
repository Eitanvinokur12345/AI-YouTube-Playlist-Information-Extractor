# Cost-Effective Model Selection for Routine Tasks

## Overview
Choose lighter, cheaper models (Sonnet, Haiku) instead of the latest flagship (Fable 5) for simple tasks like summarization, reasoning, or search to reduce API costs and usage-limit consumption.

**Use case:** When performing low-complexity tasks such as summarizing notes, basic reasoning, or simple searches, opt for Sonnet or Haiku to avoid hitting usage limits quickly and keep developer/API costs down.

## Key steps
1. Reserve Fable 5/Opus for high-complexity tasks that truly need the extra capability.
2. Monitor your usage limits when switching models to quantify savings.
