# Creating custom CLI tools from APIs/websites

## Overview
The ability for coding agents to create their own CLI tools by wrapping existing APIs or websites, using frameworks like 'CLI Anything' or 'Open CLI'.

**Use case:** Extending the capabilities of AI agents by allowing them to interact with a wider range of software and web services through custom-generated CLI interfaces.

## Key steps
1. Easier for coding agents to create themselves around other APIs.
2. Allows turning any website or software into a callable CLI tool.
