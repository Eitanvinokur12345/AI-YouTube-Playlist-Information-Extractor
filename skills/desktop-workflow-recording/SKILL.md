# Desktop Workflow Recording

## Overview
A feature in Claude that allows users to record their screen, clicks, typing, and voice to teach Claude a multi-step desktop workflow. Claude then processes this recording into a repeatable skill with a step-by-step instruction guide.

**Use case:** Automating repetitive desktop tasks, creating instructional guides for AI, enabling AI to perform complex cross-application workflows like writing a blog, converting it to PDF, and emailing it.

## Key steps
1. Ensure clear narration during recording for better skill generation.
2. Avoid typing passwords or displaying sensitive information while recording.
