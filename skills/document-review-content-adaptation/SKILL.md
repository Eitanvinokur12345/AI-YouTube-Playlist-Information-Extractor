# Document Review and Content Adaptation

## Overview
Reviews a document in full to identify its thesis, key claims, supporting evidence, and gaps. It can flag contradictions with prior work (if context is provided) and generates five thoughtful reader questions. The output is structured to facilitate content creation for various platforms like social media threads, LinkedIn posts, newsletters, and emails.

**Use case:** Efficiently analyze documents for key insights and repurpose content for multiple communication channels, ensuring consistency and relevance.

## Key steps
1. Define a clear role for the AI (e.g., 'chief of staff').
2. Specify all input sources and timeframes.
3. Strictly define the output format (e.g., markdown, one page max, bullet points, specific sections).
4. Include a hard termination condition to prevent rambling and ensure concise output.
