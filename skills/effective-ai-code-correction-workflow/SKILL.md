# Effective AI Code Correction Workflow

## Overview
A workflow for interacting with AI coding assistants, specifically Claude, that emphasizes clearing context and refining prompts after a maximum of two failed correction attempts to prevent the AI from being confused by previous incorrect solutions.

**Use case:** Debugging, code generation, and problem-solving with AI coding assistants.

## Key steps
1. Never correct Claude Code more than twice on the same problem.
2. After two failed corrections, clear the context and reset the session.
3. Rewrite the prompt using insights gained from the two failures (e.g., constraints missed, files ignored).
4. A clean session with a sharp, precise prompt is more effective than a messy session with many corrections.
