# Effective Prompting for Claude Code

## Overview
Techniques to improve interactions with Claude Code, moving beyond basic prompts to more structured and reusable approaches.

**Use case:** Improving AI output and efficiency in coding and task automation.

## Key steps
1. Avoid writing a brand new prompt every time.
2. Turn best prompts into reusable skills.
3. Provide tools, scripts, examples, and files, not just instructions.
4. Keep each skill small and focused (e.g., one for research, one for design, one for testing).
5. Iteratively update skills based on feedback and errors to improve performance over time.
