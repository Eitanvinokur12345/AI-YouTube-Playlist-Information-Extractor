# Efficient Context Provision (Pointing at Files)

## Overview
Directing the AI to specific files or code segments using file paths, allowing the AI to open and read only the necessary parts, instead of pasting large blocks of code directly into the chat.

**Use case:** Reducing context size, improving AI's ability to understand relevant code, and saving time from manual pasting.

## Key steps
1. The AI can open files itself; don't paste them.
2. Pasting 600 lines is gone; let it read what it needs.
