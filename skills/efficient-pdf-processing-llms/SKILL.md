# Efficient PDF processing for LLMs

## Overview
Optimizing PDF documents for large language models (LLMs) to reduce token usage and improve comprehension, typically by converting them into structured text formats like Markdown.

**Use case:** Reducing costs and improving accuracy when interacting with LLMs using document inputs.

## Key steps
1. Convert PDFs to structured text (e.g., Markdown) before uploading to LLMs.
2. Utilize tools like MarkItDown to automate conversion and reduce token consumption.
