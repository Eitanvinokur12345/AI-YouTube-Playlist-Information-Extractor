# Email Triage and Drafting

## Overview
Categorizes unread Gmail messages and drafts replies in the user's voice based on previous sent emails. It identifies threads needing replies, drafts informational responses, and flags already handled items. Drafts are saved in Gmail with a specific label.

**Use case:** Streamline email management, reduce time spent on drafting routine replies, and ensure consistent communication style.

## Key steps
1. Define a clear role for the AI (e.g., 'chief of staff').
2. Specify all input sources and timeframes.
3. Strictly define the output format (e.g., markdown, one page max, bullet points, specific sections).
4. Include a hard termination condition to prevent rambling and ensure concise output.
