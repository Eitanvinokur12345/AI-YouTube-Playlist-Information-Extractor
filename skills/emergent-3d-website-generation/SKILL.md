# Emergent 3D Landing Page Generation

## Overview
Emergent's E1 Agent, powered by Claude Opus 4.7, generates production-quality 3D websites with scroll-triggered animations from a product video and master prompt—replacing work that designers charge hundreds of thousands of dollars for.

## Key Techniques
- AI video generator → create product video first
- Emergent E1 Agent + Claude Opus 4.7 for generation
- Master prompt text file to guide design style
- Inspiration URL to reference an existing 3D website style
- Output: 3D website with scroll-triggered animations

## How to Apply
1. Create a product video using an AI video generator
2. Open Emergent → select Landing Page → choose E1 Agent → select Claude Opus 4.7
3. Upload your product video
4. Attach the master prompt text file
5. Add an inspiration URL of a 3D site you admire
6. Click Generate → review the output in ~5 minutes

Generated a 3D website with insane scroll-triggered animations in 5 minutes from a product video—designers would charge hundreds of thousands for equivalent work.
