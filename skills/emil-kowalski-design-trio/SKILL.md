# Emil Kowalski AI Website Design Trio

## Overview
AI-generated websites suffer three systematic problems: flat animations, generic typography (usually Inter font), and no visual hierarchy. Emil Kowalski's three-skill approach solves each: proper motion easing, Impeccable for typography polish, and Taste to teach AI models better design principles at the system level.

## Key Techniques
- **Motion with proper easing**: Replace CSS `transition: all 0.3s` with spring physics and intentional easing curves
- **Impeccable commands**: Refined typography, spacing, and layout polish via Impeccable's command set
- **Taste design system**: Teach AI models design principles rather than prescribing exact visual styles

## How to Apply
**Layer 1 — Fix Motion:**
Tell Claude: "Replace all transitions with motion using proper easing. Use `spring` animations for interactive elements and `ease-out` for reveal animations. Never use `all` in transitions."

**Layer 2 — Apply Impeccable:**
Install or reference Impeccable's design commands and tell Claude: "Run Impeccable on the typography and layout. Fix font sizes to a proper typographic scale, fix spacing to 4px/8px grid, ensure no orphan lines."

**Layer 3 — Apply Taste:**
Reference the Taste design system (by Emil Kowalski) and tell Claude: "Apply Taste design principles. Avoid Inter for body text unless this is developer tooling. Avoid pure #000000 text. Avoid radiused buttons over 8px unless the brand demands it."

## Examples
- Generic AI landing page → after trio: proper spring button hover animation, Lora + Inter type pairing with scale, minimal shadow system
- Generic AI dashboard → after trio: smooth panel transitions, precise 8px-grid spacing, intentional color weights
