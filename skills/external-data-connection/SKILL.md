# External Data Connection

## Overview
Connecting Claude to external applications and services like Google Drive, Gmail, Calendar, Slack, and GitHub to allow it to access and utilize real-time data and context from these sources.

**Use case:** Enabling Claude to work with current, real-world data from various platforms for more informed and actionable responses.

## Key steps
1. Link Google Drive, Gmail, Calendar, and other relevant apps in Claude's 'Connectors' settings.
2. Explore the connector directory for additional integrations like Canva, Figma, Jira, and Slack.
