# Firecrawl

## Overview
A skill that empowers AI agents with clean web data by allowing them to crawl, scrape, and interact with the web at scale. It bypasses common web security features like CAPTCHAs and rate limiting, providing more efficient and effective data extraction than built-in browser tools.

**Use case:** Searching the web, scraping content from web pages, interacting with live pages (clicks, forms, navigation), crawling entire websites for data extraction, gathering competitive intelligence, market research.

## Key steps
1. Free plan offers 1,000 credits per month.
2. Significantly better at crawling and scraping than Claude's default browser.
3. Can extract structured JSON data from web pages.
