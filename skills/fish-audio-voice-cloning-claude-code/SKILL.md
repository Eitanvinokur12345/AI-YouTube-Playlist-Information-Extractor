# Voice Cloning via Fish Audio in Claude Code

## Overview
Wires Fish Audio's free S2.1 Pro voice-cloning model into Claude Code so a short voice sample
can be cloned and used to read out any text, entirely from inside a coding-agent workflow.

## Key Techniques
- Use Fish Audio's free tier (S2.1 Pro model) instead of a paid voice-cloning service.
- Integrate it into Claude Code via a short setup snippet plus a free API key.
- Fine-tune the cloned voice with emotion tags for more natural narration.

## How to Apply
1. Search "Fish Audio coding agents" and follow the first result to get the Claude Code
   integration snippet; paste it into Claude Code and run it.
2. Search "Fish Audio API keys," create a free key, and paste it back into Claude Code.
3. Upload a 15-second sample of your voice.
4. Ask Claude to "clone my voice," then have it read out any script.
5. Add emotion fine-tuning if the output needs to sound less flat.
