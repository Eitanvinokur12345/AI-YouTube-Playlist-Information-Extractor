# Free AI API Key Sourcing (Google AI Studio + OpenRouter + Groq)

## Overview
A workflow for building AI apps/agents without paying for API access, combining three free
providers that each cover a different need: Google's own models, a unified router across
several free open models, and very fast inference.

## Key Techniques
- **Google AI Studio** — free Gemini API keys, best for Google's own models.
- **OpenRouter** — one unified API for multiple free models (DeepSeek, Qwen, Kimi), useful
  when you want to swap models without changing integration code.
- **Groq Cloud** — free access to 50+ open-source models with very fast inference, useful
  when latency matters more than model choice.

## How to Apply
1. Sign up for Google AI Studio and generate a free Gemini API key for Google-model work.
2. Sign up for OpenRouter for a single API key that can call multiple free models.
3. Sign up for Groq Cloud when you need fast inference across open-source models.
4. Route different parts of a project to whichever of the three fits: Google models via AI
   Studio, model flexibility via OpenRouter, or speed via Groq.
