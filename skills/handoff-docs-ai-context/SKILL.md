# Using Handoff Docs to Maintain AI Context

## Overview
A method to preserve and transfer AI conversation context by summarizing previous interactions into a handoff document that can be shared with new AI threads.

**Use case:** When an AI thread runs out of context or performs worse due to long conversations, use a handoff doc to summarize and transfer context to a new thread for better performance.

## Key steps
1. Ask the AI to summarize the entire thread before starting a new one.
2. Use the summary as input to the next AI thread to maintain continuity.
3. Keep summaries concise but comprehensive to maximize context retention.
