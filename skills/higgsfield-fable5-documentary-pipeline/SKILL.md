# Single-Prompt Documentary Generation with Higgsfield MCP

## Overview
Use Higgsfield MCP connected to Claude Fable 5 to generate a full documentary or playable game from a single text prompt. The agent autonomously sources public domain footage (e.g., NASA), plans visual beats, generates missing AI shots, and exports a final MP4 using the Higgsfield Supercomputer.

**Use case:** Generating complete video documentaries or game content from a single prompt without any manual video editing

## Key steps
1. Use public domain sources (NASA footage) to fill gaps where AI generation isn't needed
2. Higgsfield Supercomputer handles the heavy compute for batch video generation
3. The same pipeline generates games as well as videos from a single prompt
