# Higgsfield MCP UGC Campaign Workflow

## Overview
The Higgsfield MCP connects Claude to Higgsfield AI's marketing platform, enabling a complete UGC ad production pipeline from a single product image inside one conversation. The workflow runs trend research, content planning, batch video generation, and Meta Ads scheduling without leaving Claude.

## Key Techniques
- Use Higgsfield MCP Stage 1 to research live niche trends on TikTok, Instagram, and YouTube
- Stage 2: build a multi-format content plan (hooks, angles, CTAs)
- Stage 3: generate UGC videos in all planned formats from one product image
- Pair with GPT Image 2.0 in parallel for the static asset pack
- Stage 4: schedule directly to Meta Ads from the same chat

## How to Apply
1. Install the Higgsfield MCP and the Higgsfield Content Factory skill in Claude.
2. Run Stage 1: research current trends in your product niche.
3. Stage 2: generate a content plan with 5+ video formats and messaging angles.
4. Stage 3: generate all video formats at scale from your product image.
5. Review cost breakdown; schedule to Meta Ads via Stage 4.
6. Run GPT Image 2.0 in parallel to generate a static image asset pack.

## Examples
- Generating a full batch of UGC ads and publishing to Meta Ads in a single Claude session
- Creating 5 distinct video formats (different hooks, angles) from one product image with no re-uploading
