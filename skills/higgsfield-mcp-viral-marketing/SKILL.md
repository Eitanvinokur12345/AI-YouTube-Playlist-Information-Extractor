# AI Viral Marketing Agent with Higgsfield MCP

## Overview
By connecting Claude Code to the Higgsfield MCP server, this workflow automates viral marketing campaigns from product images through to generated video content. It analyzes behavioral patterns to inform targeting, then uses Higgsfield's AI video generation to produce campaign assets—replacing a marketing team for physical product businesses.

## Key Techniques
- Install Higgsfield MCP in Claude Code for direct AI video generation
- Analyze product images for behavioral triggers before generating content
- Run autonomous campaign loops that generate, test, and iterate video content

## How to Apply
1. Install Higgsfield MCP: use the install URL from higgsfield.ai/s/mcp-higgsfieldai-Fmapog
2. Connect to Claude Code by adding to mcpServers config
3. Provide product images to Claude and request behavioral pattern analysis
4. Ask Claude to generate marketing video scripts based on the analysis
5. Use Higgsfield MCP tool calls to generate the actual videos
6. Review outputs and iterate on messaging/visuals

## Examples
- Generating toy product videos that trigger "unboxing excitement" behavioral patterns
- Running A/B campaign loops where Claude generates and scores 10 video variants
