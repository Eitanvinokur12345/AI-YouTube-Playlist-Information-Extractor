# I Have ADHD (Direct-Answer Claude Skill)

## Overview
A Claude Code plugin skill that strips conversational filler ("Great question," "Hope this
helps," unnecessary explanation) and instead leads directly with what to do: numbered steps,
lists capped at five items, ending on one clear next action.

## Key Techniques
- Lead with the action, not the explanation.
- Number every step instead of describing it in prose.
- Cap lists at five items to avoid overwhelming detail.
- End every response with exactly one clear next action.

## How to Apply
1. Install the skill as a Claude Code plugin.
2. Activate it by typing `/i-have-adhd`.
3. Ask your normal question (e.g. a debugging or how-to question).
4. Expect a direct answer: "Run this command. Open this file. Change these lines. Then run
   the test." instead of paragraphs of explanation.
5. It also works with Codex and Cursor, not just Claude Code.

## Examples
Instead of three paragraphs explaining why code is broken, the skill responds with the exact
numbered actions to take — run a command, open a file, change specific lines, run the test.
