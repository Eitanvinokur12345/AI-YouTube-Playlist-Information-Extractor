# Identity Eraser

## Overview
A custom Claude Code skill designed to automatically remove a person's personal information from people-search sites and data brokers. It discovers which brokers expose personal data (name, address, phone, age, relatives) and then submits official opt-out/removal requests, handling verification codes as needed.

**Use case:** Automated removal of personal information from data broker websites to enhance online privacy.

## Key steps
1. Requires the Chrome connector to be installed.
2. Input full legal name (including variants), date of birth, current and previous addresses, phone numbers, email addresses, and close relatives' first names for comprehensive scrubbing.
