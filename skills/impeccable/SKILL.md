# Impeccable — Claude Design Knowledge Skill

## Overview
A Claude Code skill that provides deep design knowledge and a library of 18 specific commands to precisely steer design outputs. Solves the vocabulary gap problem in AI design: when something looks wrong but you can't articulate what.

## Key Techniques
- 18 specific design commands to adjust visual results with precision
- Deep design knowledge baked into the skill's instruction set
- Iterative command application: pick a command, review, apply another

## How to Apply
1. Install the Impeccable skill in Claude Code
2. Generate your initial UI/design with Claude Code
3. When something looks off, use one of the 18 commands to steer direction
4. Iterate: apply commands one at a time until the result meets your standards

## Examples
- A UI that looks "too corporate" → use Impeccable's specific command for a more editorial or modern feel
- A layout with poor visual hierarchy → apply the relevant hierarchy command to restructure
- Colors or typography that feel generic → use Impeccable's taste-refinement commands
