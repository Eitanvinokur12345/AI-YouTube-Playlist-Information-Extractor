# Inbox Triage AI Agent

## Overview
Automatically reads and categorizes incoming emails based on specified importance criteria to prioritize reading important emails first.

**Use case:** Helps users save time by filtering and prioritizing emails, reducing time spent skimming through less important messages.

## Key steps
1. Define clear importance criteria for email categorization.
2. Regularly update rules to adapt to changing email patterns.
