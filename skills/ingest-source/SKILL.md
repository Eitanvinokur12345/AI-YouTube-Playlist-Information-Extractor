# Ingest Source

## Overview
Takes any article, YouTube link, transcript, PDF, or note, routes it to the right folder (knowledge/ or projects/ based on stability), adds a summary block at the top (source, date, key people, key concepts), cross-links related notes with [[wikilinks]] on first mention, and creates any folders that don't exist yet. It pre-analyzes data to make it easy for Claude to find specific information later.

**Use case:** Building a personal knowledge base for future reference and efficient information retrieval.
