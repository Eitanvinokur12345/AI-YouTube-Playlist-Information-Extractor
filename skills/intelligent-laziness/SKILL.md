# Intelligent Laziness

## Overview
A strategy to identify tasks with diminishing returns (Zone 1) and delegate them to AI, freeing up time for high-impact tasks (Zone 2).

**Use case:** Prioritizing tasks, optimizing time management, avoiding 'completion bias'.

## Key steps
1. Identify tasks that yield capped payoffs (e.g., formatting, internal emails).
2. Delegate these tasks to AI to achieve 'good enough' results quickly.
