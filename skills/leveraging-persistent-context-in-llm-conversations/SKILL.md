# Leveraging persistent context in LLM conversations

## Overview
Utilizing pre-loaded memories, instructions, and files within an LLM project to automatically inform every new conversation, leading to more relevant and accurate responses.

**Use case:** Ensuring that the LLM always has access to critical background information, brand guidelines, or research data without needing to re-enter it.

## Key steps
1. Regularly update project memory with new insights.
2. Ensure instructions are comprehensive and cover all common scenarios.
3. Upload all relevant documents and data files.
