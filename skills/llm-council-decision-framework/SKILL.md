# LLM Council Multi-Agent Decision Framework

## Overview
A Claude Code skill that prevents the AI from simply agreeing with you by routing your decision through five specialized adversarial agents. A chairman agent then synthesizes all perspectives into one clear recommendation with a concrete next step.

## Key Techniques
- Contrarian agent: finds flaws in any proposed course of action
- First Principles Thinker: ignores the stated question and determines what you're actually trying to solve
- Expansionist: identifies upside and opportunities you're missing
- Outsider: given no context so it catches obvious blind spots
- Executor: focuses only on what the next concrete action should be

## How to Apply
1. Install the LLM Council skill in Claude Code
2. Type "Ask the Council" followed by your decision or question
3. Each of the 5 agents responds with their perspective
4. Agents then peer-review each other's answers
5. Chairman agent synthesizes everything into one final recommendation with a next step

## Examples
- "Ask the Council: should I launch my SaaS now or wait 3 more months?"
- "Ask the Council: should I hire a freelancer or build this feature myself?"
- Useful for any decision where you'd otherwise just get Claude to validate your existing plan
