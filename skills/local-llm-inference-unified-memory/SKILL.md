# Local LLM inference on unified memory hardware

## Overview
Running large language models locally on hardware with unified CPU/GPU memory (like Nvidia RTX Spark) to perform inference without cloud connectivity, enabling offline use and data privacy.

**Use case:** Execute AI prompts offline, keep sensitive data local, avoid cloud inference costs and latency.

## Key steps
1. Requires hardware with sufficient unified memory (e.g., 128GB) for larger models
2. Smaller models can run on less memory for simpler tasks
