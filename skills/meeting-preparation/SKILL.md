# Meeting Preparation

## Overview
Prepares a one-page brief for meetings by identifying external attendees, reviewing past interactions (emails, shared docs, LinkedIn updates, PR posts), summarizing unresolved points from previous conversations, and generating three open questions to ask.

**Use case:** Ensure thorough preparation for meetings, understand attendee context, and focus discussions on unresolved issues.

## Key steps
1. Define a clear role for the AI (e.g., 'chief of staff').
2. Specify all input sources and timeframes.
3. Strictly define the output format (e.g., markdown, one page max, bullet points, specific sections).
4. Include a hard termination condition to prevent rambling and ensure concise output.
