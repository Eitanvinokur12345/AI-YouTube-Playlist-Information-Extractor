# ML Hands-On Learning Strategy (70/30 Rule)

## Overview
A structured methodology for learning AI and ML effectively: allocate 70% of learning time to building real projects and 30% to theory. Prioritizes public portfolio-building over passive tutorial consumption.

**Use case:** Accelerate AI/ML skill acquisition and visibility by replacing tutorial hopping with project-driven learning
**Output:** A growing public portfolio of ML projects on GitHub with accompanying LinkedIn write-ups

## Key techniques & how to apply
1. Apply the 70/30 rule: build 2× as much as you study.
2. Learn in public — post projects to GitHub and explain what you built on LinkedIn.
3. Finish one structured resource completely before switching to another.

## General tips
- Recruiters hire on demonstrated projects, not certificates.
