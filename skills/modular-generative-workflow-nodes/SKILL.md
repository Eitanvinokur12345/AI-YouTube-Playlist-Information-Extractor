# Modular Generative Workflow with Nodes

## Overview
Build and edit generative creative workflows by connecting modular nodes representing different models or processes, allowing selective updates without breaking the entire workflow.

**Use case:** Creating complex multimedia projects where individual components like image generation, video, camera controls, voice, and translation can be adjusted independently while maintaining overall workflow coherence.

## Key steps
1. Use nodes to isolate changes to specific parts of the workflow for efficient iteration.
2. Combine different media types (image, video, voice) within one connected workflow for richer outputs.
3. Leverage AI agents to auto-generate workflows from natural language descriptions.
