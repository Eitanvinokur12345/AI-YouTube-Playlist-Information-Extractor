# Morning Briefing Automation

## Overview
Automates the creation of a one-page morning briefing by pulling information from Gmail (inbox, sent), Slack (DMs, mentions, channels), Calendar (today/tomorrow meetings with attendee context), Polymarket (open positions, P&L), and news sources (filtered by keywords). The output is a markdown brief with summaries, suggested actions, and flagged 'noise' items.

**Use case:** Quickly get up to speed on overnight communications, commitments, and relevant news to start the workday efficiently.

## Key steps
1. Define a clear role for the AI (e.g., 'chief of staff').
2. Specify all input sources and timeframes.
3. Strictly define the output format (e.g., markdown, one page max, bullet points, specific sections).
4. Include a hard termination condition to prevent rambling and ensure concise output.
