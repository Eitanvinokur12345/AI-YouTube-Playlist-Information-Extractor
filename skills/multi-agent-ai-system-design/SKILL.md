# Multi-agent AI system design

## Overview
Designing and implementing AI systems that leverage multiple specialized agents to analyze problems from different perspectives, peer-review findings, and synthesize comprehensive verdicts.

**Use case:** Overcoming AI biases like 'yes-man' tendencies, improving decision-making, generating diverse insights.

## Key steps
1. Define distinct roles for each agent (e.g., Contrarian, First Principles, Expansionist, Outsider, Executor).
2. Implement a peer-review mechanism to refine and challenge initial agent responses.
3. Include a synthesis or 'chairman' agent to consolidate findings and identify agreements/clashes.
