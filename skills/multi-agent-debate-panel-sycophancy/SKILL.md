# Multi-Agent Debate Panel for Sycophancy Reduction

## Overview
Deploy a panel of 5 AI agents that argue opposing positions to counteract sycophantic agreement bias in a single model. The technique converts Claude's tendency to over-agree (Stanford: 41% too much) into structured debate output.

**Use case:** Getting honest, critical feedback from Claude instead of validation
**Output:** Balanced multi-perspective analysis from a 5-agent debate team

## Key techniques & how to apply
1. Use 5 agents with explicitly opposing stances to force genuine disagreement
2. Prompt each agent to argue its assigned position before synthesizing conclusions
