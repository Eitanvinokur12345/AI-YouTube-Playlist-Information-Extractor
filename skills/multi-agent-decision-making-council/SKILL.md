# Multi-Agent Decision Making Council

## Overview
A method of using multiple AI agents with distinct roles (contrarian, first principles thinker, expansionist, outsider, executor) to analyze a problem from different perspectives, followed by review agents that challenge and pressure test responses, culminating in a chairman agent that synthesizes a clear decision.

**Use case:** Improving complex decision making by leveraging diverse AI perspectives and rigorous review to reduce bias and surface overlooked opportunities.

## Key steps
1. Assign distinct, well-defined roles to each agent to cover different angles of the problem.
2. Use review agents to rigorously challenge and pressure test initial agent outputs.
3. Have a final chairman agent synthesize and summarize the debate into one actionable decision.
