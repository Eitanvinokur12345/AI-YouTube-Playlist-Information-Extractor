# Multi-Agent Social Reaction Simulation

## Overview
Simulates how thousands of real people react to any document by building a knowledge graph from the document and running hundreds of AI agents with unique personalities, demographics, and memories. Used for PR crisis testing, policy analysis, trading signals, and prediction market research.

## Key Techniques
- Use Mirofish (open-source) to spin up hundreds of persona agents from a document
- Each agent has a unique personality and simulated memory, producing diverse reactions
- Run Mirofish Offline for fully local, private English-language simulations

## How to Apply
1. Clone the Mirofish GitHub repository.
2. Upload your document (press release, policy draft, earnings report).
3. Configure the persona diversity settings (demographics, political leanings, expertise levels).
4. Run the simulation — agents build a knowledge graph and react in real time.
5. Review the simulated reaction feed for sentiment patterns, key objections, and unexpected angles.
6. Use the output to refine your document before public release.

## Examples
- PR team uploads a crisis statement to Mirofish and discovers that a specific paragraph triggers disproportionate negative reactions among a key demographic — before publication.
- A policy analyst tests three versions of a regulation draft and picks the one with the most balanced simulated public response.
