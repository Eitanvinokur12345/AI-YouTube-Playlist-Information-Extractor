# Nano Banana Claude Skill

## Overview
A Claude skill that wires Google's Nano Banana (Gemini) image model into Claude via a Google AI Studio API key, so you can generate and edit images from inside Claude with the /banana command. Setup is three steps and takes about thirty seconds.

## Key Techniques
- Install the Google Banana skill by pasting its URL into Claude.
- Generate a Google AI Studio API key and drop it into Claude.
- Trigger generation with /banana.

## How to Apply
A Claude skill that wires Google's Nano Banana (Gemini) image model into Claude via a Google AI Studio API key, so you can generate and edit images from inside Claude with the /banana command. Setup is three steps and takes about thirty seconds.

## Examples
Generate and edit images (e.g., room redesigns) directly inside Claude. AI-generated and edited images.
