# Natural Language Video Editing

## Overview
Editing videos by describing desired changes in natural language, which Claude then converts into code for rendering. Features include silence removal, adding subtitles, creating intros/outros, and multi-resolution exports.

**Use case:** Adding captions to a talking head video, cutting dead air from a recording, extracting a 30-second clip for Instagram, or rendering for specific platforms like TikTok or Twitter.
