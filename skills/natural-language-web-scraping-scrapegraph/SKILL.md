# Natural Language Web Scraping with ScrapeGraph AI

## Overview
Use ScrapeGraph AI to scrape websites using plain natural language prompts instead of writing complex CSS/XPath selectors. Supports single-page, multi-page, and automated search-and-extract workflows via Python.

**Use case:** Extracting structured data from websites without manual scraping code
**Output:** Structured scraped data, Python scripts, optionally audio content

## Key techniques & how to apply
1. Use SmartScraperGraph for single-page structured extraction with a natural language prompt
2. ScrapeGraph AI works with local models via Ollama to avoid API costs

## General tips
- Open-source AI scraping tools can replace paid platforms like Apify and Bright Data for many use cases
