# OpenMontage AI Video Production with Claude Code

## Overview
OpenMontage is a free, open-source tool that turns Claude Code into a full AI video production studio. Describe your video in plain language; Claude handles scripting, footage sourcing from Archive.org, AI visual generation, Piper TTS voiceover, and Remotion+FFmpeg editing.

## Key Techniques
- Plain-language video description as input
- Claude Code as the orchestrating agent
- Piper TTS for local, free voiceover generation
- Archive.org for royalty-free footage
- Remotion + FFmpeg for video rendering and editing
- Zero-key path: all tools run locally, no paid API required

## How to Apply
1. Install OpenMontage (GitHub, open-source)
2. Ensure Piper TTS, Remotion, and FFmpeg are installed locally
3. Describe the video you want in plain language (prompt to Claude Code)
4. Claude handles scripting → footage search → visual generation → voiceover → editing
5. Review the rendered output and iterate with follow-up prompts

## Examples
Used to make explainers, trailers, ads, and educational videos for free. A full video production pipeline with no API costs—everything runs locally.
