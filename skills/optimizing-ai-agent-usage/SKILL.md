# Optimizing AI Agent Usage

## Overview
A strategy for maximizing the value of AI coding agent subscriptions by leveraging different models within a plan. This involves using more powerful, but potentially more expensive, 'frontier' models for high-level planning and cheaper, smaller models for detailed implementation tasks to stretch the monthly token quota further.

**Use case:** Maximizing cost-efficiency and token usage for AI coding agent subscriptions.

## Key steps
1. Use frontier models (e.g., Claude Opus) for planning complex tasks.
2. Use smaller, cheaper models (e.g., Claude Sonnet) for implementing details or less complex parts of the code.
3. Understand the underlying API costs and token quotas of each model within your subscription plan.
