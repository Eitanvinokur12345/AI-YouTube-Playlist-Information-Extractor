# Optimizing Claude Code Reasoning Effort

## Overview
Adjusting Claude Code's reasoning effort level to 'max' to improve the depth and quality of its problem-solving and code generation, especially for complex tasks. This consumes more tokens but can prevent failures on hard projects.

**Use case:** Enhancing AI-generated code, tackling challenging coding projects, improving AI problem-solving depth.

## Key steps
1. Set reasoning effort to 'max' using the `/effort` command.
