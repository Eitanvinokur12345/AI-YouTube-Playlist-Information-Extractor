# Using Opus and Sonnet models to optimize Claude Code token usage

## Overview
A method to reduce token usage and avoid rate limits in Claude Code by using the Opus model for planning and the Sonnet model for building within the slash command interface.

**Use case:** Minimizing token consumption and avoiding rate limits when coding with Claude Code on a pro plan.

## Key steps
1. Use the slash command '/model' and specify 'Opus plan' to set the planning model.
2. Switch to 'Sonnet' for the building phase to save tokens.
3. Activate plan mode explicitly with '/plan' to ensure proper workflow.

## Slash commands
- `/model`
- `/plan`
