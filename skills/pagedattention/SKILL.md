# PagedAttention

## Overview
A technique designed to fix KV Cache Fragmentation in Large Language Models (LLMs), which helps prevent OutOfMemory errors by efficiently managing VRAM consumption during inference.

**Use case:** Optimizing LLM deployment, reducing VRAM usage, improving throughput and handling larger batch sizes or context windows.
