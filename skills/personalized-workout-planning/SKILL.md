# Personalized Workout Planning

## Overview
Using AI to generate and adjust workout plans based on individual health data and calendar availability.

**Use case:** Creating custom fitness routines, adapting plans based on recovery and performance metrics.

## Key steps
1. Connect Claude to Apple Health and Calendar for data-driven adjustments.
2. Utilize project instructions to define the AI's role as a personal trainer.
3. Allow Claude to read health data like sleep, steps, heart rate for optimal plan generation.
