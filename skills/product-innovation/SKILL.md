# Product Innovation

## Overview
Identifying areas where common app functionalities can be significantly improved (e.g., '10x better') to create a superior user experience.

**Use case:** Differentiating an app in a competitive market by focusing on overlooked details.

## Key steps
1. Analyze how other apps handle common tasks and brainstorm ways to make them more efficient or enjoyable.
2. Even if users don't consciously notice a change immediately, repeated use will highlight the improved 'feel'.
