# Project-Based AI Interaction

## Overview
Organizing AI conversations and knowledge into distinct projects, each with its own set of instructions, goals, and output formats, to maintain focus and consistency within specific tasks.

**Use case:** Managing different work streams or topics with tailored AI assistance, ensuring rules and context are applied consistently within each project.

## Key steps
1. Name projects after real jobs or tasks (e.g., 'Weekly Team Update')
2. Open the instructions panel for each project and fill it with role, goal, and output format
3. Keep replies under a specified word count (e.g., 120 words)
