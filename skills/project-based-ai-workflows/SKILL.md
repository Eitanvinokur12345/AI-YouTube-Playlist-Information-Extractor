# Project-Based AI Workflows

## Overview
Organizing AI interactions and knowledge within specific projects, allowing Claude to draw on project-specific documents and instructions.

**Use case:** Managing complex tasks, long-term projects, or recurring activities with dedicated context and resources.

## Key steps
1. Create a new project for each major task or ongoing work stream.
2. Upload relevant documents and files directly to the project.
3. Set project-specific instructions to guide Claude's responses within that project.
