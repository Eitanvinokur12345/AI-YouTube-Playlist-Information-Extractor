# Project-based Context Management

## Overview
Creating and managing projects in Claude to provide specific context, brand guidelines, and objectives for a set of related conversations, preventing the need to start from scratch.

**Use case:** Organizing AI interactions around specific work initiatives, ensuring consistent output aligned with project goals and existing assets.

## Key steps
1. Create a new project for each major work initiative.
2. Drop in relevant files, brand guidelines, and context into the project.
3. Define project instructions to guide Claude's responses within that project.
