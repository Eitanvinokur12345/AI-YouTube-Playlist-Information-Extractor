# Project-Based Learning for Coding

## Overview
A learning methodology focused on acquiring coding and engineering skills (including software and AI engineering) by actively building projects from day one, rather than passively consuming educational content. It emphasizes choosing projects slightly beyond current capabilities to force learning and practical application.

**Use case:** Learning software engineering, AI engineering, and general programming skills effectively; building a portfolio for job interviews.

## Key steps
1. Pick projects to build from day one.
2. Choose projects that are a little beyond what you currently know how to do.
3. Take an input, send it to a model, do something useful with it, build a cool app for yourself.
4. Focus on building tangible things that can be showcased in interviews.
