# Project-Based Learning (Machine Learning)

## Overview
A learning methodology focused on building practical machine learning projects to gain experience and apply theoretical knowledge, rather than solely studying theory.

**Use case:** Accelerating learning in ML by actively creating and experimenting, leading to deeper understanding and practical skills.

## Key steps
1. Prioritize building over extensive theoretical study at the beginning.
2. Use failures in projects as opportunities to learn necessary theory.
