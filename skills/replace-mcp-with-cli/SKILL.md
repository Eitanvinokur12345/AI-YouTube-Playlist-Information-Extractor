# Replacing MCP servers with CLI tools for AI agents

## Overview
The technique of migrating AI agent integrations from MCP (likely a server-based API interaction method) to CLI (Command Line Interface) tools to improve efficiency, reduce context window usage, and increase speed.

**Use case:** Optimizing AI agent performance and resource usage when interacting with external services.

## Key steps
1. Saves an average of 40% of context window.
2. Increases speed of tool use.
3. Reduces token usage by approximately 10x.
