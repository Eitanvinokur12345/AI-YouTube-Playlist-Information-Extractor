# Resetting Claude sessions after two failed corrections

## Overview
A workflow to improve Claude's response accuracy by resetting the session after two failed correction attempts to avoid context pollution.

**Use case:** When Claude fails to fix a problem after two correction attempts, clear the context and rewrite the prompt incorporating lessons from previous failures.

## Key steps
1. Do not attempt more than two corrections in the same session.
2. Clear the context after two failed fixes.
3. Rewrite the prompt using insights from previous failed attempts.
