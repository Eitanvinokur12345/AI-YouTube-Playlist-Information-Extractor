# Retrospective Harness Optimization (RHO)

## Overview
A method for an AI agent to improve its own harness purely from its own unlabeled past trajectories, with no validation set and no external grading. It involves selecting hard and diverse past tasks, running multiple attempts, checking for self-validation and self-consistency, diagnosing failures, and proposing harness updates.

**Use case:** Autonomous improvement of AI agent systems based on past performance and failures.
