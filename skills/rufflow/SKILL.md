# Rufflow

## Overview
Rufflow is an open-source framework that spins up 60+ specialized AI agents inside Claude Code, with 'queen' manager agents coordinating 'worker' agents through shared memory. It auto-routes each task to the right agent by complexity to cut token cost and stretch usable Claude Code time.

## Key Techniques
- Let the queen agent coordinate workers so each subtask auto-routes by complexity.
- Shared memory between agents reduces redundant API calls and cuts cost.
- It's open-source and free - install it from the #1 trending agent repo on GitHub.
