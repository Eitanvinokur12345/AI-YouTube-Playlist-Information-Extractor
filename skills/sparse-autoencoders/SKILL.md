# Sparse Autoencoders

## Overview
A type of autoencoder that forces sparsity in its hidden layer activations, making neural network features more interpretable by ensuring that only a small number of neurons are active at any given time.

**Use case:** Making neural network features interpretable and disentangling information within neural network activations.
