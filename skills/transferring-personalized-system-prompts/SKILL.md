# Transferring personalized system prompts between AI models

## Overview
A method to export a detailed system prompt from one AI model and import it into another to maintain personalized interactions and context.

**Use case:** Switching from ChatGPT to Claude while preserving user-specific context, communication style, and project details.

## Key steps
1. Ensure the system prompt contains all relevant personal and project information.
2. Test the imported prompt by asking the AI about your identity and preferences.
3. Save changes after pasting the prompt in the new AI profile settings.
