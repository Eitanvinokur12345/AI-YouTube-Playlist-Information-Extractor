# Truth Prompting for AI

## Overview
A technique to create a system prompt for AI models, guiding them to be explicit about uncertainty, flag unknown information, label sources, avoid assuming context, separate fact from inference, avoid overconfidence, acknowledge disagreements, and correct mistakes immediately. This aims to reduce AI 'hallucinations' and improve factual accuracy.
