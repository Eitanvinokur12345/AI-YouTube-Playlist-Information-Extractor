# Tweet Writer

## Overview
Distills any long piece of writing (blog post, article, essay, report, script, newsletter, transcript) into a single tweet (max 280 characters). ALWAYS use this skill when the user wants to turn a long text into a tweet, or says things like "tweet this", "make a tweet", "tweet version", "twitter post", "compress to tweet", "write a tweet about [topic]", "tweet you", or pastes a large block of text and asks for a short social post. Works with pasted text, uploaded files, or URLs. Produces 3 tweet options ranked by style, ready to copy.

**Use case:** Turning long-form content into short, punchy tweets.

## Key steps
1. Keep it under 280 characters
2. Make it punchy
3. No hashtags
