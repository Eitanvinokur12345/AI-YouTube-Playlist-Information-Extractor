# UGC Video Creation with AI

## Overview
Utilizing AI (specifically Claude with the Arcads Claude Code skill) to generate user-generated content (UGC) style videos based on provided product images and detailed prompts, including script generation and creative direction.

**Use case:** Marketing, product promotion, content creation, social media campaigns.

## Key steps
1. Provide a clear product photo for visual reference.
2. Detail the desired concept, script structure (hook, show, verdict, tag), creator look, and audio preferences.
3. Specify the number of variations for the generated video.
