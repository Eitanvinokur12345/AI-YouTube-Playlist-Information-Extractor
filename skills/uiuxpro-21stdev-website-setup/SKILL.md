# UIUXPRO MAX + 21st.dev MCP Website Setup for Claude Code

## Overview
Two installations transform Claude Code from a basic HTML generator to a professional web design tool: the UIUXPRO MAX skill (a GitHub-hosted design intelligence package) and 21st.dev's Magic MCP Server (provides access to professional UI components at build time).

## Key Techniques
- **UIUXPRO MAX**: 50+ UI styles, 21 color palettes, 50 font pairings — injected as Claude's design reference
- **21st.dev Magic MCP**: Real-time access to professionally designed UI components, proper animations, glassmorphism effects
- **Combined output**: Websites with correct animation easing, glassmorphism, gradient layouts, and cinematic design — out of the box

## How to Apply
**Step 1 — Install UIUXPRO MAX:**
1. Search "UIUXPRO MAX" on GitHub
2. Copy the repository URL
3. In Claude Code, type: `install this skill: [URL]`
4. Claude confirms installation of the design intelligence package

**Step 2 — Install 21st.dev Magic MCP:**
1. Go to 21st.dev and copy the Magic MCP server install command
2. In Claude Code, type: `install this MCP server: [command]`
3. Claude confirms MCP installation

**After setup**, any build request produces websites with:
- Real animations with proper easing curves (not CSS `transition: all 0.3s`)
- Glassmorphism effects correctly applied
- Gradient schemes from the UIUXPRO color palettes
- Professional typographic hierarchy

## Examples
- "Build me a SaaS landing page" → Claude outputs a page with glassmorphism hero, proper button hover animations, gradient CTA section
- "Create a portfolio site" → Claude selects a cinematic dark theme with the right font pairing and motion effects
