# Vibe Coding Mobile App with Claude Code

## Overview
This skill covers the end-to-end process of building and publishing a revenue-generating mobile app using Claude Code with zero prior coding knowledge. Using React Native + Expo as the framework, the user supplies design inspiration and product logic while Claude Code handles all implementation.

## Key Techniques
- Use Dribbble for UI design inspiration before prompting Claude Code
- Let Claude Code scaffold the full React Native + Expo project
- Iterate through build → test → fix cycles entirely through natural language
- Publish directly to the App Store from the terminal via Expo

## How to Apply
1. Find 3–5 design references on Dribbble for your target UI.
2. Describe your app concept and desired features to Claude Code.
3. Let Claude scaffold the React Native + Expo project and implement core features.
4. Test on a real device via the Expo Go app during development.
5. Describe any bugs or missing features in plain English for Claude to fix.
6. Follow Claude's guidance to build and submit to the App Store.

## Examples
- Rebuilding a coin-valuation app (CoinSnap: $500K/month) by a developer with zero coding experience
- Shipping a fully functional React Native app with photo analysis and coin identification
