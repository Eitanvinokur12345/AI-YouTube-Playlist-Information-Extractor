# VibeSec-Skill

## Overview
An AI skill that integrates bug bounty hunting experience directly into your AI coding workflow. It teaches LLM models to write secure code from the start and audits existing codebases for common vulnerabilities like SQL injection, missing authorization layers, path traversal, and weak passwords.

**Use case:** Auditing code for security vulnerabilities, preventing common security flaws in AI-generated code, ensuring secure application deployment, performing security checks during development.

## Key steps
1. Run this skill before deploying to production to audit your codebase.
2. Helps prevent issues like leaked API keys, unauthenticated access, and data dumps.
3. Covers 60-70% of common vulnerabilities.
