# Weekly Status Report Generation

## Overview
Generates weekly status reports tailored for different audiences (internal, client, board) by pulling data from Linear (closed issues), Notion (created/edited docs), Slack (status, shipping, design channels), and Calendar (meeting counts, deep work blocks). Reports include sections on shipped, in-flight, and blocked items, with metrics for board reports.

**Use case:** Automate the creation of comprehensive and audience-specific weekly reports, saving significant time on data aggregation and formatting.

## Key steps
1. Define a clear role for the AI (e.g., 'chief of staff').
2. Specify all input sources and timeframes.
3. Strictly define the output format (e.g., markdown, one page max, bullet points, specific sections).
4. Include a hard termination condition to prevent rambling and ensure concise output.
